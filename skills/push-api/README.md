# push-api

An agent skill for Push API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill push-api
```

Then ask the agent to apply Push API.

## What it covers

- when subscribing to or delivering a web push message
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status          |
| -------- | --------------- |
| Push API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Push API](https://www.w3.org/TR/push-api/): Working Draft, push-api WD-push-api-20261005 (Working Draft, 2026-10-05).
- [Generic Event Delivery Using HTTP Push](https://www.rfc-editor.org/rfc/rfc8030.html): RFC, RFC 8030.
- [Message Encryption for Web Push](https://www.rfc-editor.org/rfc/rfc8291.html): RFC, RFC 8291.
- [Voluntary Application Server Identification (VAPID) for Web Push](https://www.rfc-editor.org/rfc/rfc8292.html): RFC, RFC 8292.
