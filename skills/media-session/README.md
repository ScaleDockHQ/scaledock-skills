# media-session

An agent skill for Media Session.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill media-session
```

Then ask the agent to apply Media Session.

## What it covers

- when exposing media metadata and controls
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status          |
| ------------- | --------------- |
| Media Session | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
