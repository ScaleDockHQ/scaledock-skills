# window-management

An agent skill for Window Management.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill window-management
```

Then ask the agent to apply Window Management.

## What it covers

- when placing windows on multiple screens
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line              | Status          |
| ----------------- | --------------- |
| Window Management | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
