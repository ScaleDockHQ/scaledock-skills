# shacl

An agent skill for SHACL.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill shacl
```

Then ask the agent to apply SHACL.

## What it covers

- when validating an RDF graph with shapes
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                               | Status          |
| ---------------------------------- | --------------- |
| Shapes Constraint Language (SHACL) | current         |
| SHACL 1.2 Core                     | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Shapes Constraint Language (SHACL)](https://www.w3.org/TR/shacl/): Recommendation, shacl REC-shacl-20170720 (Recommendation, 2017-07-20).
- [SHACL 1.2 Core](https://www.w3.org/TR/shacl12-core/): Working Draft, shacl12-core REC-shacl-20170720 (Working Draft, 2026-09-18).
