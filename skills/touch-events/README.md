# touch-events

An agent skill for Touch Events.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill touch-events
```

Then ask the agent to apply Touch Events.

## What it covers

- when handling touch events
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status  |
| ------------ | ------- |
| Touch Events | current |
