# unicode-bidi

An agent skill for Unicode Bidirectional Algorithm (UAX #9).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode-bidi
```

Then ask the agent to apply Unicode Bidirectional Algorithm (UAX #9).

## What it covers

- when ordering bidirectional text
- The version lines in the table below, pinned to the revisions in `metadata.json`.
