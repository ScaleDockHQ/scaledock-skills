# cldr

An agent skill for Unicode Locale Data Markup Language (UTS #35).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill cldr
```

Then ask the agent to apply Unicode Locale Data Markup Language (UTS #35).

## What it covers

- when reading CLDR locale data
- The version lines in the table below, pinned to the revisions in `metadata.json`.
