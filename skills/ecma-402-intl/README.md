# ecma-402-intl

An agent skill for ECMA-402 Internationalization API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill ecma-402-intl
```

Then ask the agent to apply ECMA-402 Internationalization API.

## What it covers

- when formatting numbers, dates or collation with Intl
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line           | Status          |
| -------------- | --------------- |
| ECMA-402 2026  | current         |
| ECMA-402 2025  | supported       |
| ECMA-402 2024  | supported       |
| ECMA-402 draft | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.
