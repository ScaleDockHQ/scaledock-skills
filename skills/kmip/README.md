# kmip

An agent skill for KMIP.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill kmip
```

Then ask the agent to apply KMIP.

## What it covers

- when managing cryptographic keys over KMIP
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status  |
| -------- | ------- |
| KMIP 3.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [KMIP 3.0](https://docs.oasis-open.org/kmip/kmip-spec/v3.0/kmip-spec-v3.0.html): OASIS Standard, KMIP 3.0, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
