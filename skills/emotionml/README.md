# emotionml

An agent skill for EmotionML.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill emotionml
```

Then ask the agent to apply EmotionML.

## What it covers

- when annotating emotion
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                    | Status  |
| --------------------------------------- | ------- |
| Emotion Markup Language (EmotionML) 1.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Emotion Markup Language (EmotionML) 1.0](https://www.w3.org/TR/emotionml/): Recommendation, emotionml REC-emotionml-20140522 (Recommendation, 2014-05-22).
