# pointer-events

An agent skill for Pointer Events.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill pointer-events
```

Then ask the agent to apply Pointer Events.

## What it covers

- when handling mouse, pen and touch with one event model
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                   | Status          |
| ---------------------- | --------------- |
| Pointer Events Level 3 | current         |
| Pointer Events Level 4 | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Pointer Events](https://www.w3.org/TR/pointerevents3/): Recommendation, pointerevents3 REC-pointerevents3-20260630 (Recommendation, 2026-06-30).
- [Pointer Events](https://www.w3.org/TR/pointerevents4/): Working Draft, pointerevents4 WD-pointerevents4-20260826 (Working Draft, 2026-10-05).
