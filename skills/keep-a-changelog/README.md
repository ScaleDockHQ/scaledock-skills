# keep-a-changelog

An agent skill for Keep a Changelog.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill keep-a-changelog
```

Then ask the agent to apply Keep a Changelog.

## What it covers

- when writing a changelog
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                   | Status  |
| ---------------------- | ------- |
| Keep a Changelog 1.1.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.
