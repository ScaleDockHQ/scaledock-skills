# websocket

An agent skill for The WebSocket Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill websocket
```

Then ask the agent to apply The WebSocket Protocol.

## What it covers

- when speaking the WebSocket protocol
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                          | Status  |
| --------------------------------------------- | ------- |
| RFC 6455 The WebSocket Protocol               | current |
| RFC 8441 Bootstrapping WebSockets with HTTP/2 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 6455 The WebSocket Protocol](https://www.rfc-editor.org/rfc/rfc6455.html): PROPOSED STANDARD, RFC 6455 (PROPOSED STANDARD, December 2).
- [RFC 8441 Bootstrapping WebSockets with HTTP/2](https://www.rfc-editor.org/rfc/rfc8441.html): PROPOSED STANDARD, RFC 8441 (PROPOSED STANDARD, September ).
