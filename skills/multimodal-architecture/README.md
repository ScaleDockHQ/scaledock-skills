# multimodal-architecture

An agent skill for Multimodal Architecture.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill multimodal-architecture
```

Then ask the agent to apply Multimodal Architecture.

## What it covers

- when composing a multimodal interaction
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                   | Status  |
| -------------------------------------- | ------- |
| Multimodal Architecture and Interfaces | current |

`references/versions.md` says which line to use and how to upgrade between them.
