# scxml

An agent skill for SCXML.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill scxml
```

Then ask the agent to apply SCXML.

## What it covers

- when writing a state machine in SCXML
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                                    | Status  |
| ----------------------------------------------------------------------- | ------- |
| State Chart XML (SCXML): State Machine Notation for Control Abstraction | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [State Chart XML (SCXML): State Machine Notation for Control Abstraction](https://www.w3.org/TR/scxml/): Recommendation, scxml REC-scxml-20150901 (Recommendation, 2015-09-01).
