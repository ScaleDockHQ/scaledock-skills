# oembed

An agent skill for oEmbed.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill oembed
```

Then ask the agent to apply oEmbed.

## What it covers

- when embedding a resource with oEmbed
- The version lines in the table below, pinned to the revisions in `metadata.json`.
