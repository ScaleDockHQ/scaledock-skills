# fullscreen

An agent skill for Fullscreen API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill fullscreen
```

Then ask the agent to apply Fullscreen API.

## What it covers

- when entering fullscreen
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                           | Status  |
| ------------------------------ | ------- |
| Fullscreen API Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
