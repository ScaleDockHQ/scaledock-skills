# nis2

An agent skill for NIS2 Directive: applying the NIS2 cybersecurity duties.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill nis2
```

Then ask your agent to apply NIS2 Directive.

## What it covers

- Directive (EU) 2022/2555 of 14 December 2022 on measures for a high common level of cybersecurity across the Union, published in Official Journal L 333 of 27 December 2022.

## Versions

| Line                     | Status  |
| ------------------------ | ------- |
| Directive (EU) 2022/2555 | current |

`references/versions.md` says which line to use and how to upgrade between them.
