# nist-ssdf

An agent skill for NIST SP 800-218.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill nist-ssdf
```

Then ask the agent to apply NIST SP 800-218.

## What it covers

- when applying the Secure Software Development Framework
- The version lines in the table below, pinned to the revisions in `metadata.json`.
