# ecmascript

An agent skill for ECMAScript.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill ecmascript
```

Then ask the agent to apply ECMAScript.

## What it covers

- when writing JavaScript against a published ECMAScript edition
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line            | Status                |
| --------------- | --------------------- |
| ECMAScript 2026 | current               |
| ECMAScript 2025 | supported             |
| ECMAScript 2024 | supported             |
| ECMAScript 2023 | legacy (upgrade from) |
| ECMAScript 2027 | preview (track)       |

`references/versions.md` says which line to use and how to upgrade between them.
