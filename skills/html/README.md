# html

An agent skill for HTML Living Standard.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill html
```

Then ask the agent to apply HTML Living Standard.

## What it covers

- when writing HTML, including forms, dialog, popover, workers, storage, canvas and import maps
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                 | Status                |
| -------------------- | --------------------- |
| HTML Living Standard | current               |
| HTML 5.2             | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [HTML Living Standard](https://html.spec.whatwg.org/review-drafts/2026-07/): Review Draft, Review Draft 2026-07 (Review Draft, 2026-07).
- [HTML 5.2](https://www.w3.org/TR/2017/REC-html52-20171214/): Retired Recommendation, REC-html52-20171214 (Retired Recommendation, 2017-12-14).
