# hotp-totp

An agent skill for HOTP: An HMAC-Based One-Time Password Algorithm.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill hotp-totp
```

Then ask the agent to apply HOTP: An HMAC-Based One-Time Password Algorithm.

## What it covers

- when verifying a one-time password
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                     | Status  |
| -------------------------------------------------------- | ------- |
| RFC 4226 HOTP: An HMAC-Based One-Time Password Algorithm | current |
| RFC 6238 TOTP: Time-Based One-Time Password Algorithm    | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 4226 HOTP: An HMAC-Based One-Time Password Algorithm](https://www.rfc-editor.org/rfc/rfc4226.html): INFORMATIONAL, RFC 4226 (INFORMATIONAL, December 2).
- [RFC 6238 TOTP: Time-Based One-Time Password Algorithm](https://www.rfc-editor.org/rfc/rfc6238.html): INFORMATIONAL, RFC 6238 (INFORMATIONAL, May 2011).
