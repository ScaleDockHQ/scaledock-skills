# odata

An agent skill for OData.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill odata
```

Then ask the agent to apply OData.

## What it covers

- when serving or querying an OData service
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line       | Status    |
| ---------- | --------- |
| OData 4.01 | current   |
| OData 4.0  | supported |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [OData 4.01](https://docs.oasis-open.org/odata/odata/v4.01/odata-v4.01-part1-protocol.html): OASIS Standard, OData 4.01 protocol, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
- [OData 4.0](https://docs.oasis-open.org/odata/odata/v4.0/os/part1-protocol/odata-v4.0-os-part1-protocol.html): OASIS Standard, OData 4.0 protocol, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
