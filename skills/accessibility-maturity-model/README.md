# accessibility-maturity-model

An agent skill for Accessibility Maturity Model.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill accessibility-maturity-model
```

Then ask the agent to apply Accessibility Maturity Model.

## What it covers

- when assessing an organization's accessibility maturity
