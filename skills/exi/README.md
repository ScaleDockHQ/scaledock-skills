# exi

An agent skill for Efficient XML Interchange.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill exi
```

Then ask the agent to apply Efficient XML Interchange.

## What it covers

- when encoding XML as EXI
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                                         | Status  |
| ---------------------------------------------------------------------------- | ------- |
| Efficient XML Interchange (EXI) Format 1.0 (Second Edition)                  | current |
| Efficient XML Interchange (EXI) Profile for limiting usage of dynamic memory | current |
| Canonical EXI                                                                | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Efficient XML Interchange (EXI) Format 1.0 (Second Edition)](https://www.w3.org/TR/exi/): Recommendation, exi REC-exi-20140211 (Recommendation, 2014-02-11).
- [Efficient XML Interchange (EXI) Profile for limiting usage of dynamic memory](https://www.w3.org/TR/exi-profile/): Recommendation, exi-profile REC-exi-profile-20140909 (Recommendation, 2014-09-09).
- [Canonical EXI](https://www.w3.org/TR/exi-c14n/): Recommendation, exi-c14n REC-exi-c14n-20180607 (Recommendation, 2018-06-07).
