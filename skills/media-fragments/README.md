# media-fragments

An agent skill for Media Fragments.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill media-fragments
```

Then ask the agent to apply Media Fragments.

## What it covers

- when addressing a fragment of a media resource
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                            | Status  |
| ------------------------------- | ------- |
| Media Fragments URI 1.0 (basic) | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Media Fragments URI 1.0 (basic)](https://www.w3.org/TR/media-frags/): Recommendation, media-frags REC-media-frags-20120925 (Recommendation, 2012-09-25).
