# prompt-api

An agent skill for Prompt API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill prompt-api
```

Then ask the agent to apply Prompt API.

## What it covers

- when a browser exposes an on-device language model to a page
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
