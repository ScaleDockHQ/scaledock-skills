# eu-product-liability

An agent skill for Product Liability Directive: assessing liability for a defective product.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eu-product-liability
```

Then ask your agent to apply Product Liability Directive.

## What it covers

- Directive (EU) 2024/2853 of 23 October 2024 on liability for defective products and repealing Council Directive 85/374/EEC, published in Official Journal L series 2024/2853 on 18 November 2024.

## Versions
