# rdf-dataset-canonicalization

An agent skill for RDF Dataset Canonicalization (RDFC-1.0).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill rdf-dataset-canonicalization
```

Then ask the agent to apply RDF Dataset Canonicalization (RDFC-1.0).

## What it covers

- when canonicalizing an RDF dataset for hashing or data integrity
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                         | Status  |

| RDF Dataset Canonicalization | current |

`references/versions.md` says which line to use and how to upgrade between them.
