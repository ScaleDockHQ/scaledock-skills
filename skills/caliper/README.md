# caliper

An agent skill for Caliper.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill caliper
```

Then ask the agent to apply Caliper.

## What it covers

- when sending learning analytics events
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line        | Status  |
| ----------- | ------- |
| Caliper 1.2 | current |

`references/versions.md` says which line to use and how to upgrade between them.

The skill was written from these sources, pinned in `metadata.json`:
