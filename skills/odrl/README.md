# odrl

An agent skill for ODRL.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill odrl
```

Then ask the agent to apply ODRL.

## What it covers

- when expressing permissions and obligations
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                             | Status  |
| -------------------------------- | ------- |
| ODRL Information Model 2.2       | current |
| ODRL Vocabulary & Expression 2.2 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [ODRL Information Model 2.2](https://www.w3.org/TR/odrl-model/): Recommendation, odrl-model REC-odrl-model-20180215 (Recommendation, 2018-02-15).
- [ODRL Vocabulary & Expression 2.2](https://www.w3.org/TR/odrl-vocab/): Recommendation, odrl-vocab REC-odrl-vocab-20180215 (Recommendation, 2018-02-15).
