# encoding

An agent skill for Encoding.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill encoding
```

Then ask the agent to apply Encoding.

## What it covers

- when encoding or decoding text
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status  |
| ------------------------ | ------- |
| Encoding Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
