# clipboard-api

An agent skill for Clipboard API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill clipboard-api
```

Then ask the agent to apply Clipboard API.

## What it covers

- when reading or writing the system clipboard
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status          |
| ------------------------ | --------------- |
| Clipboard API and events | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
