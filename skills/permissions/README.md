# permissions

An agent skill for Permissions.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill permissions
```

Then ask the agent to apply Permissions.

## What it covers

- when querying, requesting or specifying a powerful feature permission
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                       | Status          |
| -------------------------- | --------------- |
| Permissions                | current (track) |
| Permissions Policy Level 1 | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Permissions](https://www.w3.org/TR/permissions/): Working Draft, permissions WD-permissions-20251006 (Working Draft, 2025-10-06).
- [Permissions Policy](https://www.w3.org/TR/permissions-policy-1/): Working Draft, permissions-policy-1 WD-permissions-policy-1-20260922 (Working Draft, 2026-09-22).
