# idna

An agent skill for IDNA (UTS #46).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill idna
```

Then ask the agent to apply IDNA (UTS #46).

## What it covers

- when mapping internationalized domain names
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                   | Status  |
| ---------------------- | ------- |
| UTS #46                | current |
| RFC 5890 IDNA          | current |
| RFC 5891 IDNA protocol | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [UTS #46](https://www.unicode.org/reports/tr46/): Unicode Technical Standard, UTS #46 (Unicode Technical Standard, 2026-10-06).
- [RFC 5890 IDNA](https://www.rfc-editor.org/rfc/rfc5890.html): RFC, RFC 5890 (RFC, 2010-08).
- [RFC 5891 IDNA protocol](https://www.rfc-editor.org/rfc/rfc5891.html): RFC, RFC 5891 (RFC, 2010-08).
