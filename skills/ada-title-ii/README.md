# ada-title-ii

An agent skill for ADA Title II: applying ADA Title II to a state or local government service.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill ada-title-ii
```

Then ask your agent to apply ADA Title II.

## What it covers

- 28 CFR Part 35, Nondiscrimination on the Basis of Disability in State and Local Government Services, as served by the eCFR renderer for the current title 28 text.

## Versions

| Line           | Status  |
| -------------- | ------- |
| 28 CFR Part 35 | current |

`references/versions.md` says which line to use and how to upgrade between them.
