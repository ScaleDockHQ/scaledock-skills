# web-annotation

An agent skill for Web Annotation.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-annotation
```

Then ask the agent to apply Web Annotation.

## What it covers

- when creating or exchanging annotations
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                      | Status  |
| ------------------------- | ------- |
| Web Annotation Data Model | current |
| Web Annotation Protocol   | current |
| Web Annotation Vocabulary | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Web Annotation Data Model](https://www.w3.org/TR/annotation-model/): Recommendation, annotation-model REC-annotation-model-20170223 (Recommendation, 2017-02-23).
- [Web Annotation Protocol](https://www.w3.org/TR/annotation-protocol/): Recommendation, annotation-protocol REC-annotation-protocol-20170223 (Recommendation, 2017-02-23).
- [Web Annotation Vocabulary](https://www.w3.org/TR/annotation-vocab/): Recommendation, annotation-vocab REC-annotation-vocab-20170223 (Recommendation, 2017-02-23).
