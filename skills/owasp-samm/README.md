# owasp-samm

An agent skill for OWASP SAMM.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-samm
```

Then ask the agent to apply OWASP SAMM.

## What it covers

- when assessing software assurance maturity
- The version lines in the table below, pinned to the revisions in `metadata.json`.
