# sign-in-with-apple

An agent skill for Sign in with Apple.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill sign-in-with-apple
```

Then ask the agent to apply Sign in with Apple.

## What it covers

- when signing users in with Apple
- The version lines in the table below, pinned to the revisions in `metadata.json`.
