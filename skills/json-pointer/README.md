# json-pointer

An agent skill for JavaScript Object Notation (JSON) Pointer.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill json-pointer
```

Then ask the agent to apply JavaScript Object Notation (JSON) Pointer.

## What it covers

- when evaluating a JSON Pointer
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                               | Status  |
| -------------------------------------------------- | ------- |
| RFC 6901 JavaScript Object Notation (JSON) Pointer | current |

`references/versions.md` says which line to use and how to upgrade between them.
