# unicode-security

An agent skill for Unicode Security Mechanisms (UTS #39).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode-security
```

Then ask the agent to apply Unicode Security Mechanisms (UTS #39).

## What it covers

- when detecting confusable or restricted Unicode text
