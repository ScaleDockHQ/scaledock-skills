# debug-adapter-protocol

An agent skill for Debug Adapter Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill debug-adapter-protocol
```

Then ask the agent to apply Debug Adapter Protocol.

## What it covers

- when implementing a debug adapter
- The version lines in the table below, pinned to the revisions in `metadata.json`.
