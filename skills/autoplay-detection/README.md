# autoplay-detection

An agent skill for Autoplay Policy Detection.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill autoplay-detection
```

Then ask the agent to apply Autoplay Policy Detection.

## What it covers

- when detecting whether autoplay is allowed
- The version lines in the table below, pinned to the revisions in `metadata.json`.
