# picture-in-picture

An agent skill for Picture-in-Picture.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill picture-in-picture
```

Then ask the agent to apply Picture-in-Picture.

## What it covers

- when showing a video in a floating window
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
