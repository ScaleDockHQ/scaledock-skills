# wai-adapt

An agent skill for WAI-Adapt.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill wai-adapt
```

Then ask the agent to apply WAI-Adapt.

## What it covers

- when adapting content with WAI-Adapt symbols or related modules
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                         | Status          |
| -------------------------------------------- | --------------- |
| WAI-Adapt: Symbols Module Level 1.0          | current (build) |
| WAI-Adapt: Help and Support Module Level 1.0 | current (track) |
| WAI-Adapt: Tools Module Level 1.0            | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [WAI-Adapt: Symbols Module](https://www.w3.org/TR/adapt-symbols/): Candidate Recommendation Snapshot, adapt-symbols WD-SVG2-20150915 (Candidate Recommendation Snapshot, 2023-01-05).
- [WAI-Adapt: Help and Support Module](https://www.w3.org/TR/adapt-help/): Working Draft, adapt-help WD-adapt-help-20220609 (Working Draft, 2022-06-09).
- [WAI-Adapt: Tools Module](https://www.w3.org/TR/adapt-tools/): Working Draft, adapt-tools WD-adapt-tools-20220609 (Working Draft, 2022-06-09).
- [WAI-Adapt Explainer](https://www.w3.org/TR/adapt/): Draft Note, adapt (Draft Note, 2023-01-03).
- [Requirements for WAI-Adapt specification](https://www.w3.org/TR/adapt-requirements/): Draft Note, adapt-requirements (Draft Note, 2022-06-09).
