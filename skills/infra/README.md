# infra

An agent skill for Infra.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill infra
```

Then ask the agent to apply Infra.

## What it covers

- when using the Infra primitives in a spec or implementation
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                  | Status  |
| --------------------- | ------- |
| Infra Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
