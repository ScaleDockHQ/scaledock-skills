# hpke

An agent skill for Hybrid Public Key Encryption.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill hpke
```

Then ask the agent to apply Hybrid Public Key Encryption.

## What it covers

- when using hybrid public key encryption
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                  | Status  |
| ------------------------------------- | ------- |
| RFC 9180 Hybrid Public Key Encryption | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 9180 Hybrid Public Key Encryption](https://www.rfc-editor.org/rfc/rfc9180.html): INFORMATIONAL, RFC 9180 (INFORMATIONAL, February 2).
