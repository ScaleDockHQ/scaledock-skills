# xml-encryption

An agent skill for XML Encryption.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill xml-encryption
```

Then ask the agent to apply XML Encryption.

## What it covers

- when encrypting XML
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                             | Status  |
| ------------------------------------------------ | ------- |
| XML Encryption Syntax and Processing Version 1.1 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [XML Encryption Syntax and Processing Version 1.1](https://www.w3.org/TR/xmlenc-core1/): Recommendation, xmlenc-core1 REC-xmlenc-core1-20130411 (Recommendation, 2013-04-11).
