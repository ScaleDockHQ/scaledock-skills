# cacao

An agent skill for CACAO.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill cacao
```

Then ask the agent to apply CACAO.

## What it covers

- when writing security playbooks
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line      | Status  |
| --------- | ------- |
| CACAO 2.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [CACAO 2.0](https://docs.oasis-open.org/cacao/security-playbooks/v2.0/security-playbooks-v2.0.html): OASIS Standard, CACAO Security Playbooks 2.0, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
