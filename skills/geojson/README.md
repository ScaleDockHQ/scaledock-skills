# geojson

An agent skill for The GeoJSON Format.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill geojson
```

Then ask the agent to apply The GeoJSON Format.

## What it covers

- when reading or writing GeoJSON
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                        | Status  |
| --------------------------- | ------- |
| RFC 7946 The GeoJSON Format | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 7946 The GeoJSON Format](https://www.rfc-editor.org/rfc/rfc7946.html): PROPOSED STANDARD, RFC 7946 (PROPOSED STANDARD, August 201).
