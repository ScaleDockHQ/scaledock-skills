# presentation-api

An agent skill for Presentation API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill presentation-api
```

Then ask the agent to apply Presentation API.

## What it covers

- when presenting content on a second screen
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line             | Status          |
| ---------------- | --------------- |
| Presentation API | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.
