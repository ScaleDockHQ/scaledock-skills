# web-audio

An agent skill for Web Audio API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-audio
```

Then ask the agent to apply Web Audio API.

## What it covers

- when processing or synthesizing audio
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status          |
| ----------------------- | --------------- |
| Web Audio API Level 1.0 | current         |
| Web Audio API 1.1       | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Web Audio API](https://www.w3.org/TR/webaudio-1.0/): Recommendation, webaudio-1.0 REC-webaudio-20210617 (Recommendation, 2021-06-17).
- [Web Audio API 1.1](https://www.w3.org/TR/webaudio-1.1/): Working Draft, webaudio-1.1 WD-webaudio-1.1-20260922 (Working Draft, 2026-09-22).
