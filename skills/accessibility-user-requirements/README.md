# accessibility-user-requirements

An agent skill for W3C accessibility user requirements.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill accessibility-user-requirements
```

Then ask the agent to apply W3C accessibility user requirements.

## What it covers

- when gathering user requirements for media, XR, RTC, collaboration, synchronization or natural language interfaces
- The version lines in the table below, pinned to the revisions in `metadata.json`.
