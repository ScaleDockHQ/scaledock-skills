# model-signing

An agent skill for Model signing.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill model-signing
```

Then ask the agent to apply Model signing.

## What it covers

- when signing machine-learning models
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
