# fedcm

An agent skill for Federated Credential Management (FedCM).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill fedcm
```

Then ask the agent to apply Federated Credential Management (FedCM).

## What it covers

- when a browser, identity provider or relying party implements federated sign-in
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                        | Status          |
| ------------------------------------------- | --------------- |
| Federated Credential Management API Level 1 | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Federated Credential Management API](https://www.w3.org/TR/fedcm-1/): First Public Working Draft, fedcm-1 WD-fedcm-1-20240820 (First Public Working Draft, 2024-08-20).
