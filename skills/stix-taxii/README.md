# stix-taxii

An agent skill for STIX and TAXII.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill stix-taxii
```

Then ask the agent to apply STIX and TAXII.

## What it covers

- when sharing cyber threat intelligence
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line      | Status  |
| --------- | ------- |
| STIX 2.1  | current |
| TAXII 2.1 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [STIX 2.1](https://docs.oasis-open.org/cti/stix/v2.1/stix-v2.1.html): OASIS Standard, STIX 2.1, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
- [TAXII 2.1](https://docs.oasis-open.org/cti/taxii/v2.1/taxii-v2.1.html): OASIS Standard, TAXII 2.1, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
