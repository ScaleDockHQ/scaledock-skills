# bpmn

An agent skill for BPMN: drawing or exchanging a BPMN process model.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill bpmn
```

Then ask your agent to apply BPMN.

## What it covers

- Business Process Model and Notation (BPMN) Version 2.0.2, OMG document formal/2013-12-09, December 2013. The title page says version 2.0.2 contains a minor change to Clause 15.

## Versions

| Line       | Status  |
| ---------- | ------- |
| BPMN 2.0.2 | current |

`references/versions.md` says which line to use and how to upgrade between them.
