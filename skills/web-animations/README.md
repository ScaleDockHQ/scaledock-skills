# web-animations

An agent skill for Web Animations.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-animations
```

Then ask the agent to apply Web Animations.

## What it covers

- when animating with the Web Animations API
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                          | Status                |
| ----------------------------- | --------------------- |
| Web Animations Module Level 2 | current (track)       |
| Web Animations Level 1        | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Web Animations Module Level 2](https://www.w3.org/TR/web-animations-2/): Working Draft, web-animations-2 WD-web-animations-2-20251120 (Working Draft, 2025-11-20).
- [Web Animations](https://www.w3.org/TR/web-animations-1/): Working Draft, web-animations-1 WD-web-animations-1-20230605 (Working Draft, 2023-06-05).
