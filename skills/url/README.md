# url

An agent skill for URL.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill url
```

Then ask the agent to apply URL.

## What it covers

- when parsing or serializing URLs
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                | Status  |
| ------------------- | ------- |
| URL Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
