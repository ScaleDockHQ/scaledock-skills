# gamepad

An agent skill for Gamepad.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill gamepad
```

Then ask the agent to apply Gamepad.

## What it covers

- when reading gamepad input
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line    | Status          |
| ------- | --------------- |
| Gamepad | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
