# unicode-identifiers

An agent skill for Unicode Identifier and Pattern Syntax (UAX #31).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode-identifiers
```

Then ask the agent to apply Unicode Identifier and Pattern Syntax (UAX #31).

## What it covers

- when deciding which characters are identifiers
- The version lines in the table below, pinned to the revisions in `metadata.json`.
