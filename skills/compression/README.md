# compression

An agent skill for Compression.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill compression
```

Then ask the agent to apply Compression.

## What it covers

- when compressing or decompressing bytes
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                        | Status  |
| --------------------------- | ------- |
| Compression Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
