# owasp-mobile-top-10

An agent skill for OWASP Mobile Top 10.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-mobile-top-10
```

Then ask the agent to apply OWASP Mobile Top 10.
