# console

An agent skill for Console.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill console
```

Then ask the agent to apply Console.

## What it covers

- when writing console methods
- The version lines in the table below, pinned to the revisions in `metadata.json`.
