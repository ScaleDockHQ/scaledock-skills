# commonmark

An agent skill for CommonMark.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill commonmark
```

Then ask the agent to apply CommonMark.

## What it covers

- when parsing CommonMark
- The version lines in the table below, pinned to the revisions in `metadata.json`.
