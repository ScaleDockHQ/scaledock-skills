# webgpu

An agent skill for WebGPU.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webgpu
```

Then ask the agent to apply WebGPU.

## What it covers

- when rendering or computing with WebGPU or WGSL
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status          |
| ----------------------- | --------------- |
| WebGPU                  | current (build) |
| WebGPU Shading Language | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [WebGPU](https://www.w3.org/TR/webgpu/): Candidate Recommendation Draft, webgpu CRD-webgpu-20260915 (Candidate Recommendation Draft, 2026-09-15).
- [WebGPU Shading Language](https://www.w3.org/TR/WGSL/): Candidate Recommendation Draft, WGSL CRD-WGSL-20260921 (Candidate Recommendation Draft, 2026-09-21).
