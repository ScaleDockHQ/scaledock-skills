# madr

An agent skill for MADR.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill madr
```

Then ask the agent to apply MADR.

## What it covers

- when writing an architecture decision record
- The version lines in the table below, pinned to the revisions in `metadata.json`.
