# lti

An agent skill for LTI.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill lti
```

Then ask the agent to apply LTI.

## What it covers

- when integrating a learning tool
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line    | Status  |
| ------- | ------- |
| LTI 1.3 | current |

`references/versions.md` says which line to use and how to upgrade between them.
