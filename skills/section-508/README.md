# section-508

An agent skill for Section 508.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill section-508
```

Then ask the agent to apply Section 508.

## What it covers

- when applying the Revised 508 Standards
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                  | Status  |
| --------------------- | ------- |
| Revised 508 Standards | current |

`references/versions.md` says which line to use and how to upgrade between them.
