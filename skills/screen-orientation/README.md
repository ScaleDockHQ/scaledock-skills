# screen-orientation

An agent skill for Screen Orientation.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill screen-orientation
```

Then ask the agent to apply Screen Orientation.

## What it covers

- when reading or locking screen orientation
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line               | Status          |
| ------------------ | --------------- |
| Screen Orientation | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
