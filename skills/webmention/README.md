# webmention

An agent skill for Webmention.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webmention
```

Then ask the agent to apply Webmention.

## What it covers

- when sending or receiving a webmention
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line       | Status  |
| ---------- | ------- |
| Webmention | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Webmention](https://www.w3.org/TR/webmention/): Recommendation, webmention REC-webmention-20170112 (Recommendation, 2017-01-12).
