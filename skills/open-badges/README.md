# open-badges

An agent skill for Open Badges.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill open-badges
```

Then ask the agent to apply Open Badges.

## What it covers

- when issuing an Open Badge
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line            | Status  |
| --------------- | ------- |
| Open Badges 3.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Open Badges 3.0](https://www.imsglobal.org/spec/ob/v3p0/): Specification, Open Badges 3.0 (Specification, 2026-10-06).
