# openehr

An agent skill for openEHR.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill openehr
```

Then ask the agent to apply openEHR.

## What it covers

- when modeling an openEHR record
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                          | Status  |
| ----------------------------- | ------- |
| openEHR Architecture Overview | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [openEHR Architecture Overview](https://specifications.openehr.org/releases/BASE/latest/architecture_overview.html): Specification, openEHR BASE Architecture Overview, latest release (Specification, 2026-10-06).
