# xliff

An agent skill for XLIFF.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill xliff
```

Then ask the agent to apply XLIFF.

## What it covers

- when exchanging localizable content
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line      | Status  |
| --------- | ------- |
| XLIFF 2.1 | current |
| XLIFF 2.2 | preview |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [XLIFF 2.1](https://docs.oasis-open.org/xliff/xliff-core/v2.1/os/xliff-core-v2.1-os.html): OASIS Standard, XLIFF 2.1, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
- [XLIFF 2.2 Part 1: Core](https://docs.oasis-open.org/xliff/xliff-core/v2.2/cs01/xliff-core-v2.2-cs01-part1.html): Committee Specification, XLIFF 2.2 Committee Specification 01, 2025-03-13.
- [XLIFF 2.2 Part 2: Extended](https://docs.oasis-open.org/xliff/xliff-core/v2.2/cs01/xliff-extended-v2.2-cs01-part2.html): Committee Specification, XLIFF 2.2 Committee Specification 01, 2025-03-13.
