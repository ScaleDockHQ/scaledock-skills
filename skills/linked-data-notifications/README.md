# linked-data-notifications

An agent skill for Linked Data Notifications.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill linked-data-notifications
```

Then ask the agent to apply Linked Data Notifications.

## What it covers

- when sending or receiving an LDN inbox notification
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                      | Status  |
| ------------------------- | ------- |
| Linked Data Notifications | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Linked Data Notifications](https://www.w3.org/TR/ldn/): Recommendation, ldn REC-ldn-20170502 (Recommendation, 2017-05-02).
