# notifications

An agent skill for Notifications.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill notifications
```

Then ask the agent to apply Notifications.

## What it covers

- when showing a notification
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                          | Status  |
| ----------------------------- | ------- |
| Notifications Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.

The skill was written from these sources, pinned in `metadata.json`:
