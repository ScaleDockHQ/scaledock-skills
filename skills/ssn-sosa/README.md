# ssn-sosa

An agent skill for SSN and SOSA.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill ssn-sosa
```

Then ask the agent to apply SSN and SOSA.

## What it covers

- when describing sensors, observations or samples
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                            | Status          |
| ----------------------------------------------- | --------------- |
| Semantic Sensor Network Ontology Level 2017     | current         |
| Semantic Sensor Network Ontology - 2023 Edition | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Semantic Sensor Network Ontology](https://www.w3.org/TR/vocab-ssn-2017/): Recommendation, vocab-ssn-2017 REC-vocab-ssn-20171019 (Recommendation, 2017-10-19).
- [Semantic Sensor Network Ontology - 2023 Edition](https://www.w3.org/TR/vocab-ssn-2023/): Working Draft, vocab-ssn-2023 REC-vocab-ssn-20171019 (Working Draft, 2026-10-03).
