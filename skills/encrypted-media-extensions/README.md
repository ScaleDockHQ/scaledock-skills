# encrypted-media-extensions

An agent skill for Encrypted Media Extensions.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill encrypted-media-extensions
```

Then ask the agent to apply Encrypted Media Extensions.

## What it covers

- when playing encrypted media
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                               | Status          |
| ---------------------------------- | --------------- |
| Encrypted Media Extensions Level 1 | current         |
| Encrypted Media Extensions Level 2 | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Encrypted Media Extensions](https://www.w3.org/TR/encrypted-media-1/): Recommendation, encrypted-media-1 REC-encrypted-media-20170918 (Recommendation, 2017-09-18).
- [Encrypted Media Extensions](https://www.w3.org/TR/encrypted-media-2/): Working Draft, encrypted-media-2 REC-encrypted-media-20170918 (Working Draft, 2026-07-07).
- [Encrypted Media Extensions Initialization Data Format Registry](https://www.w3.org/TR/eme-initdata-registry/): Draft Registry, eme-initdata-registry (Draft Registry, 2026-07-07).
- [Encrypted Media Extensions Stream Format Registry](https://www.w3.org/TR/eme-stream-registry/): Draft Registry, eme-stream-registry (Draft Registry, 2026-07-07).
