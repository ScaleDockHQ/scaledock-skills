# csvw

An agent skill for CSV on the Web.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill csvw
```

Then ask the agent to apply CSV on the Web.

## What it covers

- when describing or converting tabular data
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                           | Status  |
| ---------------------------------------------- | ------- |
| Model for Tabular Data and Metadata on the Web | current |
| Metadata Vocabulary for Tabular Data           | current |
| Generating JSON from Tabular Data on the Web   | current |
| Generating RDF from Tabular Data on the Web    | current |

`references/versions.md` says which line to use and how to upgrade between them.

- [Metadata Vocabulary for Tabular Data](https://www.w3.org/TR/tabular-metadata/): Recommendation, tabular-metadata REC-tabular-data-model-20151217 (Recommendation, 2015-12-17).
- [Generating JSON from Tabular Data on the Web](https://www.w3.org/TR/csv2json/): Recommendation, csv2json REC-tabular-data-model-20151217 (Recommendation, 2015-12-17).
- [Generating RDF from Tabular Data on the Web](https://www.w3.org/TR/csv2rdf/): Recommendation, csv2rdf REC-tabular-data-model-20151217 (Recommendation, 2015-12-17).
