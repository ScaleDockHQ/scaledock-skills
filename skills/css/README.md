# css

An agent skill for CSS Snapshot.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill css
```

Then ask the agent to apply CSS Snapshot.

## What it covers

- when writing or reviewing CSS and choosing a snapshot
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line              | Status                |
| ----------------- | --------------------- |
| CSS Snapshot 2026 | current (track)       |
| CSS Snapshot 2025 | supported             |
| CSS Snapshot 2024 | supported             |
| CSS Snapshot 2023 | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.
