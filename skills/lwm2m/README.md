# lwm2m

An agent skill for LwM2M.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill lwm2m
```

Then ask the agent to apply LwM2M.

## What it covers

- when managing a device with LwM2M
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line      | Status  |
| --------- | ------- |
| LwM2M 1.2 | current |

`references/versions.md` says which line to use and how to upgrade between them.
