# rdfa

An agent skill for RDFa.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill rdfa
```

Then ask the agent to apply RDFa.

## What it covers

- when embedding RDF in HTML
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                           | Status  |
| ------------------------------ | ------- |
| RDFa Core 1.1 - Third Edition  | current |
| RDFa Lite 1.1 - Second Edition | current |
| HTML+RDFa 1.1 - Second Edition | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RDFa Core 1.1 - Third Edition](https://www.w3.org/TR/rdfa-core/): Recommendation, rdfa-core REC-rdfa-core-20150317 (Recommendation, 2015-03-17).
- [RDFa Lite 1.1 - Second Edition](https://www.w3.org/TR/rdfa-lite/): Recommendation, rdfa-lite REC-rdfa-lite-20150317 (Recommendation, 2015-03-17).
- [HTML+RDFa 1.1 - Second Edition](https://www.w3.org/TR/html-rdfa/): Recommendation, html-rdfa REC-html-rdfa-20150317 (Recommendation, 2015-03-17).
