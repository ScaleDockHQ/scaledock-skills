# unicode

An agent skill for Unicode Standard.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode
```

Then ask the agent to apply Unicode Standard.

## What it covers

- when handling Unicode text against a published version
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line           | Status                |
| -------------- | --------------------- |
| Unicode 18.0.0 | current               |
| Unicode 17.0.0 | supported             |
| Unicode 16.0.0 | supported             |
| Unicode 15.1.0 | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Unicode 18.0.0](https://www.unicode.org/versions/Unicode18.0.0/): Unicode Standard, Unicode 18.0.0 (Unicode Standard, 18.0.0).
- [Unicode 17.0.0](https://www.unicode.org/versions/Unicode17.0.0/): Unicode Standard, Unicode 17.0.0 (Unicode Standard, 17.0.0).
- [Unicode 16.0.0](https://www.unicode.org/versions/Unicode16.0.0/): Unicode Standard, Unicode 16.0.0 (Unicode Standard, 16.0.0).
- [Unicode 15.1.0](https://www.unicode.org/versions/Unicode15.1.0/): Unicode Standard, Unicode 15.1.0 (Unicode Standard, 15.1.0).
