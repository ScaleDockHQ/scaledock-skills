# score

An agent skill for Score.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill score
```

Then ask the agent to apply Score.

## What it covers

- when writing a Score workload spec
- The version lines in the table below, pinned to the revisions in `metadata.json`.
