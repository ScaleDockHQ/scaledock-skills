# web-midi

An agent skill for Web MIDI API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-midi
```

Then ask the agent to apply Web MIDI API.

## What it covers

- when talking to MIDI devices
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status          |
| ------------ | --------------- |
| Web MIDI API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
