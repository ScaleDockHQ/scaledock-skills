# mathml

An agent skill for MathML.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill mathml
```

Then ask the agent to apply MathML.

## What it covers

- when authoring mathematical markup
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                          | Status                |
| ------------------------------------------------------------- | --------------------- |
| MathML Core                                                   | current (build)       |
| Mathematical Markup Language (MathML) Version 4.0             | preview (track)       |
| Mathematical Markup Language (MathML) Version 3.0 2nd Edition | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [MathML Core](https://www.w3.org/TR/mathml-core/): Candidate Recommendation Snapshot, mathml-core CR-mathml-core-20250624 (Candidate Recommendation Snapshot, 2025-06-24).
- [Mathematical Markup Language (MathML) Version 4.0](https://www.w3.org/TR/mathml4/): Working Draft, mathml4 WD-mathml4-20261002 (Working Draft, 2026-10-02).
- [Mathematical Markup Language (MathML) Version 3.0 2nd Edition](https://www.w3.org/TR/MathML3/): Recommendation, MathML3 REC-MathML3-20140410 (Recommendation, 2014-04-10).
