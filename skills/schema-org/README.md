# schema-org

An agent skill for Schema.org.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill schema-org
```

Then ask the agent to apply Schema.org.

## What it covers

- when marking up structured data
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line       | Status  |
| ---------- | ------- |
| Schema.org | current |

`references/versions.md` says which line to use and how to upgrade between them.
