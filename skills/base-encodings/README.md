# base-encodings

An agent skill for The Base16, Base32, and Base64 Data Encodings.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill base-encodings
```

Then ask the agent to apply The Base16, Base32, and Base64 Data Encodings.

## What it covers

- when encoding or decoding base16, base32 or base64
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                   | Status  |
| ------------------------------------------------------ | ------- |
| RFC 4648 The Base16, Base32, and Base64 Data Encodings | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 4648 The Base16, Base32, and Base64 Data Encodings](https://www.rfc-editor.org/rfc/rfc4648.html): PROPOSED STANDARD, RFC 4648 (PROPOSED STANDARD, October 20).
