# uaag

An agent skill for User Agent Accessibility Guidelines (UAAG).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill uaag
```

Then ask the agent to apply User Agent Accessibility Guidelines (UAAG).

## What it covers

- when reviewing a user agent against UAAG
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                           | Status          |
| ---------------------------------------------- | --------------- |
| User Agent Accessibility Guidelines (UAAG) 2.0 | current (track) |
| User Agent Accessibility Guidelines 1.0        | current         |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [User Agent Accessibility Guidelines (UAAG) 2.0](https://www.w3.org/TR/UAAG20/): Note, UAAG20 NOTE-UAAG20-Reference-20151215 (Note, 2015-12-15).
- [User Agent Accessibility Guidelines 1.0](https://www.w3.org/TR/UAAG10/): Recommendation, UAAG10 REC-UAAG10-20021217 (Recommendation, 2002-12-17).
