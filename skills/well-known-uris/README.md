# well-known-uris

An agent skill for Well-Known Uniform Resource Identifiers (URIs).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill well-known-uris
```

Then ask the agent to apply Well-Known Uniform Resource Identifiers (URIs).

## What it covers

- when publishing a /.well-known/ resource
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                    | Status  |
| ------------------------------------------------------- | ------- |
| RFC 8615 Well-Known Uniform Resource Identifiers (URIs) | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 8615 Well-Known Uniform Resource Identifiers (URIs)](https://www.rfc-editor.org/rfc/rfc8615.html): PROPOSED STANDARD, RFC 8615 (PROPOSED STANDARD, May 2019).
