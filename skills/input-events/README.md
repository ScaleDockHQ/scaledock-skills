# input-events

An agent skill for Input Events.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill input-events
```

Then ask the agent to apply Input Events.

## What it covers

- when handling beforeinput and input events
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                 | Status          |
| -------------------- | --------------- |
| Input Events Level 2 | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
