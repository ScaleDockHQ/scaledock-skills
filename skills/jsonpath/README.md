# jsonpath

An agent skill for JSONPath: Query Expressions for JSON.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill jsonpath
```

Then ask the agent to apply JSONPath: Query Expressions for JSON.

## What it covers

- when querying JSON with JSONPath
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                          | Status  |
| --------------------------------------------- | ------- |
| RFC 9535 JSONPath: Query Expressions for JSON | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 9535 JSONPath: Query Expressions for JSON](https://www.rfc-editor.org/rfc/rfc9535.html): PROPOSED STANDARD, RFC 9535 (PROPOSED STANDARD, February 2).
