# device-memory

An agent skill for Device Memory API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill device-memory
```

Then ask the agent to apply Device Memory API.

## What it covers

- when reading approximate device memory
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                      | Status          |
| ------------------------- | --------------- |
| Device Memory API Level 1 | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
