# dora

An agent skill for DORA: applying the Digital Operational Resilience Act.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill dora
```

Then ask your agent to apply DORA.

## What it covers

- Regulation (EU) 2022/2554 of 14 December 2022 on digital operational resilience for the financial sector, published in Official Journal L 333 of 27 December 2022.

## Versions

| Line                      | Status  |
| ------------------------- | ------- |
| Regulation (EU) 2022/2554 | current |

`references/versions.md` says which line to use and how to upgrade between them.
