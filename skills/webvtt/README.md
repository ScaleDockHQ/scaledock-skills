# webvtt

An agent skill for WebVTT.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webvtt
```

Then ask the agent to apply WebVTT.

## What it covers

- when writing or parsing WebVTT cues
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                             | Status          |
| ------------------------------------------------ | --------------- |
| WebVTT: The Web Video Text Tracks Format Level 1 | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [WebVTT: The Web Video Text Tracks Format](https://www.w3.org/TR/webvtt1/): Candidate Recommendation Draft, webvtt1 CRD-webvtt1-20260520 (Candidate Recommendation Draft, 2026-05-20).
