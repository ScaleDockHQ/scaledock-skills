# json-canonicalization

An agent skill for JSON Canonicalization Scheme (JCS).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill json-canonicalization
```

Then ask the agent to apply JSON Canonicalization Scheme (JCS).

## What it covers

- when canonicalizing JSON for signing
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                        | Status  |
| ------------------------------------------- | ------- |
| RFC 8785 JSON Canonicalization Scheme (JCS) | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
