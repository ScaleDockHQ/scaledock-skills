# test-anything-protocol

An agent skill for Test Anything Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill test-anything-protocol
```

Then ask the agent to apply Test Anything Protocol.

## What it covers

- when emitting TAP output
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line   | Status  |
| ------ | ------- |
| TAP 14 | current |

`references/versions.md` says which line to use and how to upgrade between them.
