# eu-dsa

An agent skill for Digital Services Act: applying the Digital Services Act.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eu-dsa
```

Then ask your agent to apply Digital Services Act.

## What it covers

- Regulation (EU) 2022/2065 of 19 October 2022 on a Single Market for Digital Services (Digital Services Act), published in Official Journal L 277 of 27 October 2022.

## Versions

| Line                      | Status  |
| ------------------------- | ------- |
| Regulation (EU) 2022/2065 | current |

`references/versions.md` says which line to use and how to upgrade between them.
