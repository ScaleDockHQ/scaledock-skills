# vibration

An agent skill for Vibration API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill vibration
```

Then ask the agent to apply Vibration API.

## What it covers

- when vibrating a device
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status          |
| ------------- | --------------- |
| Vibration API | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Vibration API](https://www.w3.org/TR/vibration/): Candidate Recommendation Draft, vibration CRD-vibration-20260521 (Candidate Recommendation Draft, 2026-05-21).
