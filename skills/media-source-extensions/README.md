# media-source-extensions

An agent skill for Media Source Extensions.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill media-source-extensions
```

Then ask the agent to apply Media Source Extensions.

## What it covers

- when feeding media segments to a media element
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                             | Status          |
| -------------------------------- | --------------- |
| Media Source Extensions™ Level 1 | current         |
| Media Source Extensions™ Level 2 | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Media Source Extensions™](https://www.w3.org/TR/media-source-1/): Recommendation, media-source-1 REC-media-source-20161117 (Recommendation, 2016-11-17).
- [Media Source Extensions™](https://www.w3.org/TR/media-source-2/): Working Draft, media-source-2 REC-media-source-20161117 (Working Draft, 2026-08-07).
- [Media Source Extensions Byte Stream Format Registry](https://www.w3.org/TR/mse-byte-stream-format-registry/): Draft Registry, mse-byte-stream-format-registry (Draft Registry, 2026-06-04).
