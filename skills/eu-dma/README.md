# eu-dma

An agent skill for Digital Markets Act: applying the Digital Markets Act.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eu-dma
```

Then ask your agent to apply Digital Markets Act.

## What it covers

- Regulation (EU) 2022/1925 of 14 September 2022 on contestable and fair markets in the digital sector (Digital Markets Act), published in Official Journal L 265 of 12 October 2022.

## Versions

| Line                      | Status  |
| ------------------------- | ------- |
| Regulation (EU) 2022/1925 | current |

`references/versions.md` says which line to use and how to upgrade between them.
