# uma

An agent skill for User-Managed Access.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill uma
```

Then ask the agent to apply User-Managed Access.

## What it covers

- when granting and federating access with UMA 2.0
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                            | Status  |
| ------------------------------- | ------- |
| UMA 2.0 Grant                   | current |
| UMA 2.0 Federated Authorization | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [UMA 2.0 Grant](https://docs.kantarainitiative.org/uma/wg/rec-oauth-uma-grant-2.0.html): Recommendation, UMA 2.0 Grant for OAuth 2.0, fetched 2026-10-06 (Recommendation, 2026-10-06).
- [UMA 2.0 Federated Authorization](https://docs.kantarainitiative.org/uma/wg/rec-oauth-uma-federated-authz-2.0.html): Recommendation, UMA 2.0 Federated Authorization, fetched 2026-10-06 (Recommendation, 2026-10-06).
