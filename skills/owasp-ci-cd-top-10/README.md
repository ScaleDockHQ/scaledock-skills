# owasp-ci-cd-top-10

An agent skill for OWASP CI/CD Top 10.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-ci-cd-top-10
```

Then ask the agent to apply OWASP CI/CD Top 10.
