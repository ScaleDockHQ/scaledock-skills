# media-capabilities

An agent skill for Media Capabilities.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill media-capabilities
```

Then ask the agent to apply Media Capabilities.

## What it covers

- when querying decoding or encoding support
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line               | Status          |
| ------------------ | --------------- |
| Media Capabilities | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
