# fetch

An agent skill for Fetch.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill fetch
```

Then ask the agent to apply Fetch.

## What it covers

- when fetching resources, including CORS
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                  | Status  |
| --------------------- | ------- |
| Fetch Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.

The skill was written from these sources, pinned in `metadata.json`:
