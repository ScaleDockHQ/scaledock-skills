# dcat

An agent skill for DCAT.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill dcat
```

Then ask the agent to apply DCAT.

## What it covers

- when describing a data catalog
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                       | Status  |
| ------------------------------------------ | ------- |
| Data Catalog Vocabulary (DCAT) - Version 3 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Data Catalog Vocabulary (DCAT) - Version 3](https://www.w3.org/TR/vocab-dcat-3/): Recommendation, vocab-dcat-3 REC-vocab-dcat-3-20200204 (Recommendation, 2024-08-22).
