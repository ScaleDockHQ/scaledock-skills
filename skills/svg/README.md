# svg

An agent skill for Scalable Vector Graphics (SVG).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill svg
```

Then ask the agent to apply Scalable Vector Graphics (SVG).

## What it covers

- when authoring or processing SVG
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                | Status                |
| --------------------------------------------------- | --------------------- |
| Scalable Vector Graphics (SVG) 2                    | current (build)       |
| Scalable Vector Graphics (SVG) 1.1 (Second Edition) | legacy (upgrade from) |
| SVG Accessibility API Mappings Level 1.0            | current (track)       |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Scalable Vector Graphics (SVG) 2](https://www.w3.org/TR/SVG2/): Candidate Recommendation Snapshot, SVG2 CR-SVG2-20181004 (Candidate Recommendation Snapshot, 2018-10-04).
- [Scalable Vector Graphics (SVG) 1.1 (Second Edition)](https://www.w3.org/TR/SVG11/): Recommendation, SVG11 REC-SVG11-20110816 (Recommendation, 2011-08-16).
- [SVG Accessibility API Mappings](https://www.w3.org/TR/svg-aam-1.0/): Working Draft, svg-aam-1.0 WD-svg-aam-1.0-20260923 (Working Draft, 2026-09-24).
