# owasp-ml-top-10

An agent skill for OWASP ML Top 10: reviewing machine learning systems against the OWASP Machine Learning Security Top Ten.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-ml-top-10
```

Then ask your agent to apply OWASP ML Top 10.

## What it covers

- The OWASP Machine Learning Security Top Ten 2023 (ML01:2023 to ML10:2023): each risk's description and its How to Prevent controls, read from the project's Markdown source at a pinned commit.

## Versions

| Line            | Status  |
| --------------- | ------- |
| OWASP ML Top 10 | current |

`references/versions.md` says which line to use and how to upgrade between them.
