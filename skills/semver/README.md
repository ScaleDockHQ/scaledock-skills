# semver

An agent skill for Semantic Versioning.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill semver
```

Then ask the agent to apply Semantic Versioning.

## What it covers

- when assigning version numbers
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status  |
| ------------ | ------- |
| SemVer 2.0.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [SemVer 2.0.0](https://semver.org/spec/v2.0.0.html): Specification, Semantic Versioning 2.0.0, fetched 2026-10-06 (Specification, 2026-10-06).
