# server-sent-events

An agent skill for Server-sent events.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill server-sent-events
```

Then ask the agent to apply Server-sent events.

## What it covers

- when streaming text events from a server to a page
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line               | Status  |
| ------------------ | ------- |
| Server-sent events | current |

`references/versions.md` says which line to use and how to upgrade between them.
