# selection-api

An agent skill for Selection API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill selection-api
```

Then ask the agent to apply Selection API.

## What it covers

- when reading the current text selection
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status          |
| ------------- | --------------- |
| Selection API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
