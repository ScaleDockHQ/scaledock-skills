# compute-pressure

An agent skill for Compute Pressure API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill compute-pressure
```

Then ask the agent to apply Compute Pressure API.

## What it covers

- when observing CPU pressure
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status          |
| ------------------------ | --------------- |
| Compute Pressure Level 1 | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.
