# yaml

An agent skill for YAML.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill yaml
```

Then ask the agent to apply YAML.

## What it covers

- when parsing YAML
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line       | Status                |
| ---------- | --------------------- |
| YAML 1.2.2 | current               |
| YAML 1.1   | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [YAML 1.2.2](https://yaml.org/spec/1.2.2/): Specification, YAML 1.2.2, fetched 2026-10-06 (Specification, 2026-10-06).
- [YAML 1.1](https://yaml.org/spec/1.1/): Specification, YAML 1.1, fetched 2026-10-06 (Specification, 2026-10-06).
