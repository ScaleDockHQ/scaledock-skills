# data-on-the-web-best-practices

An agent skill for Data on the Web Best Practices.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill data-on-the-web-best-practices
```

Then ask the agent to apply Data on the Web Best Practices.

## What it covers

- when publishing data on the web
- The version lines in the table below, pinned to the revisions in `metadata.json`.
