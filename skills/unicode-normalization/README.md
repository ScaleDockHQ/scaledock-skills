# unicode-normalization

An agent skill for Unicode Normalization (UAX #15).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode-normalization
```

Then ask the agent to apply Unicode Normalization (UAX #15).

## What it covers

- when normalizing Unicode text
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| UAX #15 | current |
