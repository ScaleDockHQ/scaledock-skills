# ccpa-cpra

An agent skill for CCPA.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill ccpa-cpra
```

Then ask the agent to apply CCPA.

## What it covers

- when applying the California Consumer Privacy Act
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line | Status  |
| ---- | ------- |
| CCPA | current |

`references/versions.md` says which line to use and how to upgrade between them.
