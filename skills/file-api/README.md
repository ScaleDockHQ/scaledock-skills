# file-api

An agent skill for File API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill file-api
```

Then ask the agent to apply File API.

## What it covers

- when reading local files in the browser
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status          |
| -------- | --------------- |
| File API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
