# HEART Working Group (archived): Health Relationship Trust

There is no dedicated skill for this family. This file is the reference.

HEART is a set of profiles that let patients control how, when and with whom their clinical data is shared, built on FHIR, OAuth 2.0, OpenID Connect and UMA. The Archived Groups page lists HEART as an archived working group. The archive notice on the HEART overview page repeats the FastFed wording ("approved closing the FastFed working group ... at the September 11, 2025 board meeting"), so the exact closing date for HEART is not stated separately. Questions go to help@oidf.org.

Index: [HEART Working Group – Specifications](https://openid.net/wg/heart/specifications/) and [Archived Groups](https://openid.net/wg/archived-groups/), checked 2026-10-02. Dates come from each document's header, read on 2026-10-02.

## Final Specifications

None.

## Guidance

The group is archived and the profiles have not changed since 2018. Treat them as reference material for patient-directed health data sharing, not as a maintained standard.
