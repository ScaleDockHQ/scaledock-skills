# AB/Connect Working Group: OpenID Connect

Install the dedicated skill: `npx skills add ScaleDockHQ/scaledock-skills --skill openid-connect`

The AB/Connect working group combines the Artifact Binding and Connect working groups and produces the OAuth 2.0 based OpenID Connect specifications. It also publishes OpenID Federation; those entries are in [`federation.md`](federation.md). Its page says it also includes the OpenID for Verifiable Credentials project; the three OpenID4VC specifications are now listed under the DCP working group ([`dcp-openid4vc.md`](dcp-openid4vc.md)).

Index: [AB/Connect Working Group – Specifications](https://openid.net/wg/connect/specifications/), checked 2026-10-02. Dates come from each document's header, read on 2026-10-02.

## Final Specifications

| Specification                                                                                                                                          | Maturity and revision                  | What it defines and when to implement it                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [OpenID Connect Core 1.0 incorporating errata set 2](https://openid.net/specs/openid-connect-core-1_0.html)                                            | Final, errata set 2, December 15, 2023 | Authentication built on OAuth 2.0 and claims about the End-User. Every OP and RP implements it.                                                                                                               |
| [OpenID Connect Discovery 1.0 incorporating errata set 2](https://openid.net/specs/openid-connect-discovery-1_0.html)                                  | Final, errata set 2, December 15, 2023 | How an RP finds an OP and its metadata. Implement when RPs configure from the issuer URL.                                                                                                                     |
| [OpenID Connect Dynamic Client Registration 1.0 incorporating errata set 2](https://openid.net/specs/openid-connect-registration-1_0.html)             | Final, errata set 2, December 15, 2023 | How an RP registers with an OP and gets a client ID. Implement for open or self-service client onboarding.                                                                                                    |
| [OpenID Connect Relying Party Metadata Choices 1.0](https://openid.net/specs/openid-connect-rp-metadata-choices-1_0-final.html)                        | Final, 25 March 2026                   | Extends Dynamic Client Registration so an RP can send a set of supported values for some metadata parameters instead of a single value.                                                                       |
| [OAuth 2.0 Multiple Response Type Encoding Practices](https://openid.net/specs/oauth-v2-multiple-response-types-1_0.html)                              | Final, February 25, 2014               | Guidance on encoding responses for multiple-valued response types, new Response Type values, and the `response_mode` authorization request parameter. The index calls it "OAuth 2.0 Multiple Response Types". |
| [OAuth 2.0 Form Post Response Mode](https://openid.net/specs/oauth-v2-form-post-response-mode-1_0.html)                                                | Final, April 27, 2015                  | Returns authorization response parameters as auto-submitted HTML form values with HTTP POST. Implement when responses must not travel in the URL.                                                             |
| [OpenID 2.0 to OpenID Connect Migration 1.0](https://openid.net/specs/openid-connect-migration-1_0.html)                                               | Final, April 16, 2015                  | How to move users from OpenID 2.0 identifiers to OpenID Connect. Implement only when migrating a legacy OpenID 2.0 deployment.                                                                                |
| [OpenID Connect RP-Initiated Logout 1.0](https://openid.net/specs/openid-connect-rpinitiated-1_0.html)                                                 | Final, September 12, 2022              | How an RP asks the OP to log the End-User out.                                                                                                                                                                |
| [OpenID Connect Session Management 1.0](https://openid.net/specs/openid-connect-session-1_0.html)                                                      | Final, September 12, 2022              | How to manage OpenID Connect sessions, including postMessage-based logout.                                                                                                                                    |
| [OpenID Connect Front-Channel Logout 1.0](https://openid.net/specs/openid-connect-frontchannel-1_0.html)                                               | Final, September 12, 2022              | Logout through the browser without an OP iframe on RP pages.                                                                                                                                                  |
| [OpenID Connect Back-Channel Logout 1.0 incorporating errata set 1](https://openid.net/specs/openid-connect-backchannel-1_0.html)                      | Final, December 15, 2023               | Logout through direct OP-to-RP requests. Both index pages list it as "Second Errata"; the document title says "incorporating errata set 1".                                                                   |
| [OpenID Connect Core Error Code unmet_authentication_requirements](https://openid.net/specs/openid-connect-unmet-authentication-requirements-1_0.html) | Final, June 2019                       | The `unmet_authentication_requirements` error, so an OP can tell an RP it could not authenticate the End-User as requested.                                                                                   |
| [Initiating User Registration via OpenID Connect 1.0](https://openid.net/specs/openid-connect-prompt-create-1_0.html)                                  | Final, 2 December 2022                 | The `prompt=create` value, which starts account creation at the OP and then completes the authentication flow.                                                                                                |

## Errata Corrections

The index lists second errata for Core, Discovery, Dynamic Client Registration and Back-Channel Logout. The unversioned URLs above serve the errata editions. For Back-Channel Logout, see the note in the table.
