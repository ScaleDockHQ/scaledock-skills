# Versions and upgrades

Read this when choosing a target version, reading a document written for an older line, upgrading, or deciding whether to use a preview. Sources: the pinned texts listed in [Sources](../SKILL.md#sources).

## Version lines

| Id                     | Line                     | Status  | Revision                         | Posture | Summary                                                         |
| ---------------------- | ------------------------ | ------- | -------------------------------- | ------- | --------------------------------------------------------------- |
| `cfr-45-parts-160-164` | 45 CFR Parts 160 and 164 | current | eCFR current, fetched 2026-10-06 |         | HIPAA general, privacy, security and breach notification rules. |

Statuses: **current** is the default target; **supported** is released and still a valid target when a consumer needs it; **legacy** is superseded, read and upgraded from but never authored; **preview** is a draft of the next line, used only as its posture allows.

## Which version to use

- Default to the current line.
- Drop to a supported line only for a named consumer that cannot read the current one.
- Treat a legacy document as input to an upgrade.
- Emit nothing from a preview unless its posture is build.

The pin is the eCFR current text of title 45 parts 160 and 164 fetched on 2026-10-06. The statute itself is not this pin.
