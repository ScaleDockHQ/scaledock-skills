# anoncreds

An agent skill for AnonCreds.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill anoncreds
```

Then ask the agent to apply AnonCreds.

## What it covers

- when issuing or verifying anonymous credentials
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status  |
| ------------- | ------- |
| AnonCreds 1.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.
