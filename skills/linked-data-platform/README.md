# linked-data-platform

An agent skill for Linked Data Platform.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill linked-data-platform
```

Then ask the agent to apply Linked Data Platform.

## What it covers

- when reading or writing LDP resources
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status  |
| ------------------------ | ------- |
| Linked Data Platform 1.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Linked Data Platform 1.0](https://www.w3.org/TR/ldp/): Recommendation, ldp REC-ldp-20150226 (Recommendation, 2015-02-26).
