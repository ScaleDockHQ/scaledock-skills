# webtransport

An agent skill for WebTransport.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webtransport
```

Then ask the agent to apply WebTransport.

## What it covers

- when sending unreliable or bidirectional data to a server
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
