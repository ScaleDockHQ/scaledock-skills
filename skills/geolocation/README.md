# geolocation

An agent skill for Geolocation.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill geolocation
```

Then ask the agent to apply Geolocation.

## What it covers

- when reading a device position
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                 | Status                |
| -------------------- | --------------------- |
| Geolocation API 2016 | legacy (upgrade from) |
| Geolocation          | current (build)       |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Geolocation API 2016](https://www.w3.org/TR/2016/REC-geolocation-API-20161108/): Recommendation, geolocation-2016 REC-geolocation-API-20161108 (Recommendation, 2016-11-08).
- [Geolocation](https://www.w3.org/TR/geolocation/): Candidate Recommendation Snapshot, geolocation CR-geolocation-20260326 (Candidate Recommendation Snapshot, 2026-03-26).
