# contact-picker

An agent skill for Contact Picker API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill contact-picker
```

Then ask the agent to apply Contact Picker API.

## What it covers

- when picking contacts from the device
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line               | Status          |
| ------------------ | --------------- |
| Contact Picker API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
