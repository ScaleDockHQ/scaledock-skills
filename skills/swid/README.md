# swid

An agent skill for SWID.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill swid
```

Then ask the agent to apply SWID.

## What it covers

- when tagging software with SWID
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status  |
| ------------ | ------- |
| NIST IR 8060 | current |

`references/versions.md` says which line to use and how to upgrade between them.
