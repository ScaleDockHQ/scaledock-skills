# xml

An agent skill for XML.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill xml
```

Then ask the agent to apply XML.

## What it covers

- when parsing or producing XML
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                   | Status                |
| ------------------------------------------------------ | --------------------- |
| Extensible Markup Language (XML) 1.0 (Fifth Edition)   | current               |
| Extensible Markup Language (XML) 1.1 (Second Edition)  | legacy (upgrade from) |
| Namespaces in XML 1.0 (Third Edition)                  | current               |
| Namespaces in XML 1.1 (Second Edition)                 | legacy (upgrade from) |
| XML Inclusions (XInclude) Version 1.0 (Second Edition) | current               |
| XML Base (Second Edition)                              | current               |
| XML Entity Definitions for Characters (3rd Edition)    | current               |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources
