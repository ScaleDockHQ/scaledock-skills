# web-share

An agent skill for Web Share API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-share
```

Then ask the agent to apply Web Share API.

## What it covers

- when sharing data from a page to another app
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status  |
| ------------- | ------- |
| Web Share API | current |

`references/versions.md` says which line to use and how to upgrade between them.
