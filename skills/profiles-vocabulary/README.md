# profiles-vocabulary

An agent skill for Profiles Vocabulary.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill profiles-vocabulary
```

Then ask the agent to apply Profiles Vocabulary.

## What it covers

- when negotiating or describing a profile
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                           | Status          |
| ------------------------------ | --------------- |
| The Profiles Vocabulary 1.0    | current (track) |
| Content Negotiation by Profile | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
