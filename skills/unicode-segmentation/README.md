# unicode-segmentation

An agent skill for Unicode Text Segmentation (UAX #29).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode-segmentation
```

Then ask the agent to apply Unicode Text Segmentation (UAX #29).

## What it covers

- when splitting text into graphemes, words or sentences
- The version lines in the table below, pinned to the revisions in `metadata.json`.
