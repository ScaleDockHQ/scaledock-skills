# webfinger

An agent skill for WebFinger.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webfinger
```

Then ask the agent to apply WebFinger.

## What it covers

- when discovering a resource with WebFinger
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line               | Status  |
| ------------------ | ------- |
| RFC 7033 WebFinger | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources
