# mimesniff

An agent skill for MIME Sniffing.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill mimesniff
```

Then ask the agent to apply MIME Sniffing.

## What it covers

- when sniffing a MIME type
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                          | Status  |
| ----------------------------- | ------- |
| MIME Sniffing Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
