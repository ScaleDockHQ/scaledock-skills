# referrer-policy

An agent skill for Referrer Policy.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill referrer-policy
```

Then ask the agent to apply Referrer Policy.

## What it covers

- when choosing or applying a referrer policy on a document or request
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line            | Status          |
| --------------- | --------------- |
| Referrer Policy | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.
