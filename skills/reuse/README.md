# reuse

An agent skill for REUSE.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill reuse
```

Then ask the agent to apply REUSE.

## What it covers

- when adding machine-readable license information
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line  | Status  |
| ----- | ------- |
| REUSE | current |

`references/versions.md` says which line to use and how to upgrade between them.
