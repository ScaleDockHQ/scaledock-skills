# pkcs11

An agent skill for PKCS #11.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill pkcs11
```

Then ask the agent to apply PKCS #11.

## What it covers

- when using a cryptographic token interface
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status  |
| ------------ | ------- |
| PKCS #11 3.1 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [PKCS #11 3.1](https://docs.oasis-open.org/pkcs11/pkcs11-spec/v3.1/pkcs11-spec-v3.1.html): OASIS Standard, PKCS #11 3.1, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
