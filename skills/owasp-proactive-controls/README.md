# owasp-proactive-controls

An agent skill for OWASP Proactive Controls.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-proactive-controls
```

Then ask the agent to apply OWASP Proactive Controls.

## What it covers

- when applying proactive security controls
- The version lines in the table below, pinned to the revisions in `metadata.json`.
