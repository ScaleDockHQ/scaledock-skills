# iab-tcf

An agent skill for IAB TCF.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill iab-tcf
```

Then ask the agent to apply IAB TCF.

## What it covers

- when encoding a TCF consent string
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line    | Status  |
| ------- | ------- |
| TCF 2.2 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [TCF 2.2](https://iabeurope.eu/tcf-2-2/): Policy, TCF 2.2, fetched 2026-10-06 (Policy, 2026-10-06).
