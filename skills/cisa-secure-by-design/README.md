# cisa-secure-by-design

An agent skill for Secure by Design.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill cisa-secure-by-design
```

Then ask the agent to apply Secure by Design.

## What it covers

- when applying CISA Secure by Design
- The version lines in the table below, pinned to the revisions in `metadata.json`.
