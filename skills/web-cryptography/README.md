# web-cryptography

An agent skill for Web Cryptography API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-cryptography
```

Then ask the agent to apply Web Cryptography API.

## What it covers

- when using SubtleCrypto or CryptoKey in a browser
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                         | Status          |
| ---------------------------- | --------------- |
| Web Cryptography API Level 1 | current         |
| Web Cryptography Level 2     | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Web Cryptography API](https://www.w3.org/TR/WebCryptoAPI/): Recommendation, webcrypto-1 WD-webcrypto-2-20250422 (Recommendation, 2017-01-26).
- [Web Cryptography Level 2](https://www.w3.org/TR/webcrypto-2/): First Public Working Draft, webcrypto-2 WD-webcrypto-2-20250422 (First Public Working Draft, 2025-04-22).
