# owl-time

An agent skill for OWL Time.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owl-time
```

Then ask the agent to apply OWL Time.

## What it covers

- when describing time in OWL
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                 | Status          |
| -------------------- | --------------- |
| Time Ontology in OWL | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.
