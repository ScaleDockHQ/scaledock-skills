# conventional-commits

An agent skill for Conventional Commits.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill conventional-commits
```

Then ask the agent to apply Conventional Commits.

## What it covers

- when writing commit messages
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                       | Status  |
| -------------------------- | ------- |
| Conventional Commits 1.0.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/): Specification, Conventional Commits 1.0.0, fetched 2026-10-06 (Specification, 2026-10-06).
