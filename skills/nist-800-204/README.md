# nist-800-204

An agent skill for NIST SP 800-204.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill nist-800-204
```

Then ask the agent to apply NIST SP 800-204.

## What it covers

- when securing microservices
- The version lines in the table below, pinned to the revisions in `metadata.json`.
