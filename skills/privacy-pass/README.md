# privacy-pass

An agent skill for The Privacy Pass Architecture.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill privacy-pass
```

Then ask the agent to apply The Privacy Pass Architecture.

## What it covers

- when issuing or redeeming a Privacy Pass token
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                 | Status  |
| ---------------------------------------------------- | ------- |
| RFC 9576 The Privacy Pass Architecture               | current |
| RFC 9577 The Privacy Pass HTTP Authentication Scheme | current |
| RFC 9578 Privacy Pass Issuance Protocols             | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 9576 The Privacy Pass Architecture](https://www.rfc-editor.org/rfc/rfc9576.html): INFORMATIONAL, RFC 9576 (INFORMATIONAL, June 2024).
- [RFC 9577 The Privacy Pass HTTP Authentication Scheme](https://www.rfc-editor.org/rfc/rfc9577.html): PROPOSED STANDARD, RFC 9577 (PROPOSED STANDARD, June 2024).
- [RFC 9578 Privacy Pass Issuance Protocols](https://www.rfc-editor.org/rfc/rfc9578.html): PROPOSED STANDARD, RFC 9578 (PROPOSED STANDARD, June 2024).
