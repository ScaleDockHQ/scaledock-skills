# nist-800-171

An agent skill for NIST SP 800-171.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill nist-800-171
```

Then ask the agent to apply NIST SP 800-171.

## What it covers

- when protecting controlled unclassified information
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line             | Status  |
| ---------------- | ------- |
| SP 800-171 Rev 3 | current |

`references/versions.md` says which line to use and how to upgrade between them.
