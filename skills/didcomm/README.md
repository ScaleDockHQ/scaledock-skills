# didcomm

An agent skill for DIDComm Messaging.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill didcomm
```

Then ask the agent to apply DIDComm Messaging.

## What it covers

- when sending authenticated messages between DIDs
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                  | Status  |
| --------------------- | ------- |
| DIDComm Messaging 2.1 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [DIDComm Messaging 2.1](https://identity.foundation/didcomm-messaging/spec/v2.1/): DIF specification, DIDComm Messaging v2.1, fetched 2026-10-06 (DIF specification, 2026-10-06).
