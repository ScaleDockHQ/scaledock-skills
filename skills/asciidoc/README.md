# asciidoc

An agent skill for AsciiDoc.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill asciidoc
```

Then ask the agent to apply AsciiDoc.

## What it covers

- when writing AsciiDoc
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status  |
| -------- | ------- |
| AsciiDoc | current |

`references/versions.md` says which line to use and how to upgrade between them.
