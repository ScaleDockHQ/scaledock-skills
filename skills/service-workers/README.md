# service-workers

An agent skill for Service Workers.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill service-workers
```

Then ask the agent to apply Service Workers.

## What it covers

- when implementing a service worker or its registration
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status          |
| ----------------------- | --------------- |
| Service Workers Nightly | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Service Workers Nightly](https://www.w3.org/TR/service-workers/): Candidate Recommendation Draft, service-workers CRD-service-workers-20260917 (Candidate Recommendation Draft, 2026-09-17).
