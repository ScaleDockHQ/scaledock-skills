# uri

An agent skill for Uniform Resource Identifier (URI): Generic Syntax.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill uri
```

Then ask the agent to apply Uniform Resource Identifier (URI): Generic Syntax.

## What it covers

- when parsing URIs, IRIs, URNs or URI templates
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                       | Status  |
| ---------------------------------------------------------- | ------- |
| RFC 3986 Uniform Resource Identifier (URI): Generic Syntax | current |
| RFC 3987 Internationalized Resource Identifiers (IRIs)     | current |
| RFC 8141 Uniform Resource Names (URNs)                     | current |
| RFC 6570 URI Template                                      | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 3986 Uniform Resource Identifier (URI): Generic Syntax](https://www.rfc-editor.org/rfc/rfc3986.html): INTERNET STANDARD, RFC 3986 (INTERNET STANDARD, January 20).
- [RFC 3987 Internationalized Resource Identifiers (IRIs)](https://www.rfc-editor.org/rfc/rfc3987.html): PROPOSED STANDARD, RFC 3987 (PROPOSED STANDARD, January 20).
- [RFC 8141 Uniform Resource Names (URNs)](https://www.rfc-editor.org/rfc/rfc8141.html): PROPOSED STANDARD, RFC 8141 (PROPOSED STANDARD, April 2017).
- [RFC 6570 URI Template](https://www.rfc-editor.org/rfc/rfc6570.html): PROPOSED STANDARD, RFC 6570 (PROPOSED STANDARD, March 2012).
