# eat

An agent skill for The Entity Attestation Token (EAT).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eat
```

Then ask the agent to apply The Entity Attestation Token (EAT).

## What it covers

- when producing or verifying an entity attestation token
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                        | Status  |
| ------------------------------------------- | ------- |
| RFC 9711 The Entity Attestation Token (EAT) | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 9711 The Entity Attestation Token (EAT)](https://www.rfc-editor.org/rfc/rfc9711.html): PROPOSED STANDARD, RFC 9711 (PROPOSED STANDARD, April 2025).
