# i18n with next-intl and `next/root-params`

Locales, files, routes, locale resolution, the next-intl plugin, and how copy is written and translated.

- **Locales.** `en` (source) and `nl`, with `localePrefix: "never"`. The locale comes from the `profile-locale` cookie, kept in sync with `profiles.locale`.
- **Files:**
  - `lib/i18n/locale.ts`: `locales = ["en", "nl"] as const`, `AppLocale`, `defaultLocale`, `resolveLocale()`.
  - `lib/i18n/routing.ts`: `defineRouting({ locales, defaultLocale, localePrefix: "never", localeCookie: { name: "profile-locale" } })`.
  - `lib/i18n/navigation.ts`: `createNavigation(routing)`.
- **Routes.**
  - Localized routes live under `app/[locale]/...`, and the `[locale]` layout exports `generateStaticParams()`.
  - Never add `app/layout.tsx` above `[locale]`. `app/global-not-found.tsx` covers everything outside it.
  - `locale` is the only root param.
- **`lib/i18n/request.ts`** resolves the locale in this order:
  1. The explicit `locale` override.
  2. `await rootParams.locale()`, checked with `hasLocale`.
  3. In `catch`: `unstable_rethrow(error)` first, then `await requestLocale`.
  4. `defaultLocale`.

  Messages load from `translations/<locale>.po`.

- **Layout.** The `[locale]` layout calls `await getLocale()` for `<html lang>`. It never calls `setRequestLocale` and never awaits `params`.
- **Proxy.** `proxy.ts` composes `createMiddleware(routing)` with the session refresh. Token-only public routes bypass i18n. Routes outside `[locale]` negotiate `Accept-Language` in a Suspense island.
- **Plugin:** `createNextIntlPlugin({ requestConfig: "./lib/i18n/request.ts", experimental: { srcPath: "./", extract: true, messages: { path: "./translations", locales: "infer", format: "po", sourceLocale: "en", precompile: true } } })`.
- **Copy.**
  - Use only `useExtracted` and `const t = await getExtracted(...)`, with `t({ id, message, description })`.
  - Call `getExtracted` as a direct statement, never inside `Promise.all`.
  - Never use `t.raw`, `useTranslations` or `getTranslations`.
- **Client catalogs.** `NextIntlClientProvider messages={null}` wraps a per-locale `ClientMessagesProvider` (an exhaustive `switch` with one hashed chunk per locale).
- **Where translation happens.** Packages ship codes and English defaults, and apps translate at the edge. Every `msgstr` is filled, and a test fails on empty entries.
