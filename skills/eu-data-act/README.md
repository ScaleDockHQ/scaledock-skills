# eu-data-act

An agent skill for Data Act: applying the Data Act to access and use of data.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eu-data-act
```

Then ask your agent to apply Data Act.

## What it covers

- Regulation (EU) 2023/2854 of 13 December 2023 on harmonised rules on fair access to and use of data (Data Act).

## Versions

| Line                      | Status  |
| ------------------------- | ------- |
| Regulation (EU) 2023/2854 | current |

`references/versions.md` says which line to use and how to upgrade between them.
