# attribution

An agent skill for Attribution API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill attribution
```

Then ask the agent to apply Attribution API.

## What it covers

- when measuring conversions without cross-site identifiers
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                | Status          |
| ------------------- | --------------- |
| Attribution Level 1 | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
