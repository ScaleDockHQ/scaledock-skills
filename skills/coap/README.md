# coap

An agent skill for The Constrained Application Protocol (CoAP).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill coap
```

Then ask the agent to apply The Constrained Application Protocol (CoAP).

## What it covers

- when speaking the Constrained Application Protocol
- The version lines in the table below, pinned to the revisions in `metadata.json`.
