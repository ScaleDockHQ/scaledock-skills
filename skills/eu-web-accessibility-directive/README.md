# eu-web-accessibility-directive

An agent skill for Web Accessibility Directive: making a public-sector website or mobile application accessible.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eu-web-accessibility-directive
```

Then ask your agent to apply Web Accessibility Directive.

## What it covers

- Directive (EU) 2016/2102 of 26 October 2016 on the accessibility of the websites and mobile applications of public sector bodies, published in Official Journal L 327 of 2 December 2016.
