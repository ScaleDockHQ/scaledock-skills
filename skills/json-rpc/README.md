# json-rpc

An agent skill for JSON-RPC.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill json-rpc
```

Then ask the agent to apply JSON-RPC.

## What it covers

- when calling procedures over JSON-RPC 2.0
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status  |
| ------------ | ------- |
| JSON-RPC 2.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.
