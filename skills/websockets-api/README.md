# websockets-api

An agent skill for WebSockets API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill websockets-api
```

Then ask the agent to apply WebSockets API.

## What it covers

- when opening a WebSocket from a page
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                       | Status  |
| -------------------------- | ------- |
| WebSockets Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
