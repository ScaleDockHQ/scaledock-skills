# rif

An agent skill for RIF.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill rif
```

Then ask the agent to apply RIF.

## What it covers

- when exchanging rules
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                         | Status  |
| -------------------------------------------- | ------- |
| RIF Core Dialect (Second Edition)            | current |
| RIF Basic Logic Dialect (Second Edition)     | current |
| RIF Production Rule Dialect (Second Edition) | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RIF Core Dialect (Second Edition)](https://www.w3.org/TR/rif-core/): Recommendation, rif-core REC-rif-core-20130205 (Recommendation, 2013-02-05).
- [RIF Basic Logic Dialect (Second Edition)](https://www.w3.org/TR/rif-bld/): Recommendation, rif-bld REC-rif-bld-20130205 (Recommendation, 2013-02-05).
- [RIF Production Rule Dialect (Second Edition)](https://www.w3.org/TR/rif-prd/): Recommendation, rif-prd REC-rif-prd-20130205 (Recommendation, 2013-02-05).
