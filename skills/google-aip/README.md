# google-aip

An agent skill for AIP.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill google-aip
```

Then ask the agent to apply AIP.

## What it covers

- when designing an API with Google AIP guidance
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line | Status  |
| ---- | ------- |
| AIPs | current |

`references/versions.md` says which line to use and how to upgrade between them.
