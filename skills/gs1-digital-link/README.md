# gs1-digital-link

An agent skill for GS1 Digital Link.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill gs1-digital-link
```

Then ask the agent to apply GS1 Digital Link.

## What it covers

- when encoding a GS1 identifier in a URI
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                        | Status  |
| --------------------------- | ------- |
| GS1 Digital Link URI Syntax | current |

`references/versions.md` says which line to use and how to upgrade between them.
