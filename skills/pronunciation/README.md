# pronunciation

An agent skill for Pronunciation.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill pronunciation
```

Then ask the agent to apply Pronunciation.

## What it covers

- when specifying how to pronounce content, or reading the pronunciation lexicon
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                  | Status          |
| ----------------------------------------------------- | --------------- |
| Explainer: Improving Spoken Presentation on the Web   | current (track) |
| Pronunciation Lexicon Specification (PLS) Version 1.0 | current         |

`references/versions.md` says which line to use and how to upgrade between them.
