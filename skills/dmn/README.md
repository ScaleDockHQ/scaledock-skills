# dmn

An agent skill for DMN: modelling a decision or its decision logic.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill dmn
```

Then ask your agent to apply DMN.

## What it covers

- Decision Model and Notation Version 1.5, OMG document formal/24-01-01, January 2024.

## Versions

| Line    | Status  |
| ------- | ------- |
| DMN 1.5 | current |

`references/versions.md` says which line to use and how to upgrade between them.
