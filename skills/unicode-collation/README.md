# unicode-collation

An agent skill for Unicode Collation Algorithm (UTS #10).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode-collation
```

Then ask the agent to apply Unicode Collation Algorithm (UTS #10).
