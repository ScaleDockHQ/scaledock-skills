# sitemaps

An agent skill for Sitemaps.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill sitemaps
```

Then ask the agent to apply Sitemaps.

## What it covers

- when publishing a sitemap
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status  |
| ------------ | ------- |
| Sitemaps 0.9 | current |

`references/versions.md` says which line to use and how to upgrade between them.
