# webnn

An agent skill for Web Neural Network API (WebNN).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webnn
```

Then ask the agent to apply Web Neural Network API (WebNN).

## What it covers

- when running a neural network graph in the browser
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
