# eu-digital-product-passport

An agent skill for Digital product passport: creating or reading a digital product passport.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eu-digital-product-passport
```

Then ask your agent to apply Digital product passport.

## What it covers

- Regulation (EU) 2024/1781 of 13 June 2024 establishing a framework for the setting of ecodesign requirements for sustainable products. The fetched text sets the digital product passport rules inside that framework.

## Versions
