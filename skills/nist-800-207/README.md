# nist-800-207

An agent skill for NIST SP 800-207.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill nist-800-207
```

Then ask the agent to apply NIST SP 800-207.

## What it covers

- when applying zero trust architecture
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line        | Status  |
| ----------- | ------- |
| SP 800-207  | current |
| SP 800-207A | current |

`references/versions.md` says which line to use and how to upgrade between them.
