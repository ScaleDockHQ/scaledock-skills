# uk-online-safety-act

An agent skill for Online Safety Act 2023.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill uk-online-safety-act
```

Then ask the agent to apply Online Safety Act 2023.

## What it covers

- when applying the UK Online Safety Act
- The version lines in the table below, pinned to the revisions in `metadata.json`.
