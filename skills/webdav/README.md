# webdav

An agent skill for HTTP Extensions for Web Distributed Authoring and Versioning (WebDAV).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webdav
```

Then ask the agent to apply HTTP Extensions for Web Distributed Authoring and Versioning (WebDAV).

## What it covers

- when implementing WebDAV, CalDAV or CardDAV
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                                                    | Status  |
| --------------------------------------------------------------------------------------- | ------- |
| RFC 4918 HTTP Extensions for Web Distributed Authoring and Versioning (WebDAV)          | current |
| RFC 4791 Calendaring Extensions to WebDAV (CalDAV)                                      | current |
| RFC 6352 CardDAV: vCard Extensions to Web Distributed Authoring and Versioning (WebDAV) | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 4918 HTTP Extensions for Web Distributed Authoring and Versioning (WebDAV)](https://www.rfc-editor.org/rfc/rfc4918.html): PROPOSED STANDARD, RFC 4918 (PROPOSED STANDARD, June 2007).
- [RFC 4791 Calendaring Extensions to WebDAV (CalDAV)](https://www.rfc-editor.org/rfc/rfc4791.html): PROPOSED STANDARD, RFC 4791 (PROPOSED STANDARD, March 2007).
- [RFC 6352 CardDAV: vCard Extensions to Web Distributed Authoring and Versioning (WebDAV)](https://www.rfc-editor.org/rfc/rfc6352.html): PROPOSED STANDARD, RFC 6352 (PROPOSED STANDARD, August 201).
