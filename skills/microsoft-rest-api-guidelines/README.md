# microsoft-rest-api-guidelines

An agent skill for Microsoft REST API Guidelines.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill microsoft-rest-api-guidelines
```

Then ask the agent to apply Microsoft REST API Guidelines.

## What it covers
