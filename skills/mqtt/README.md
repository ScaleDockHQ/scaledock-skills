# mqtt

An agent skill for MQTT.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill mqtt
```

Then ask the agent to apply MQTT.

## What it covers

- when publishing or subscribing with MQTT
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line       | Status    |
| ---------- | --------- |
| MQTT 5.0   | current   |
| MQTT 3.1.1 | supported |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [MQTT 5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html): OASIS Standard, MQTT 5.0, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
- [MQTT 3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/os/mqtt-v3.1.1-os.html): OASIS Standard, MQTT 3.1.1, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
