# privacy-principles

An agent skill for Privacy Principles.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill privacy-principles
```

Then ask the agent to apply Privacy Principles.

## What it covers

- when reviewing a web feature against the W3C privacy and ethical principles
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                   | Status          |
| ---------------------- | --------------- |
| Privacy Principles     | current (track) |
| Ethical Web Principles | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
