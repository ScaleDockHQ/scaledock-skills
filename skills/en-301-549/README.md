# en-301-549

An agent skill for EN 301 549.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill en-301-549
```

Then ask the agent to apply EN 301 549.

## What it covers

- when applying European ICT accessibility requirements
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line              | Status    |
| ----------------- | --------- |
| EN 301 549 V4.1.1 | current   |
| EN 301 549 V3.2.1 | supported |

`references/versions.md` says which line to use and how to upgrade between them.
