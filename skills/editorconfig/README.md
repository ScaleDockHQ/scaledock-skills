# editorconfig

An agent skill for EditorConfig.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill editorconfig
```

Then ask the agent to apply EditorConfig.

## What it covers

- when defining editor settings
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line         | Status  |
| ------------ | ------- |
| EditorConfig | current |

`references/versions.md` says which line to use and how to upgrade between them.
