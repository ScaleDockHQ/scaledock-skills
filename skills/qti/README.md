# qti

An agent skill for QTI: exchanging a QTI assessment item, section or test.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill qti
```

Then ask your agent to apply QTI.

## What it covers

- 1EdTech Question and Test Interoperability (QTI) Assessment, Section and Item Information Model Version 3.0.1, 1EdTech Final Release, issued 1 September 2024.

## Versions

| Line      | Status  |
| --------- | ------- |
| QTI 3.0.1 | current |

`references/versions.md` says which line to use and how to upgrade between them.
