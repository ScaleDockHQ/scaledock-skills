# publication-manifest

An agent skill for Publication Manifest.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill publication-manifest
```

Then ask the agent to apply Publication Manifest.

## What it covers

- when writing a publication manifest or audiobook
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                 | Status  |
| -------------------- | ------- |
| Publication Manifest | current |
| Audiobooks           | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Publication Manifest](https://www.w3.org/TR/pub-manifest/): Recommendation, pub-manifest REC-json-ld-20140116 (Recommendation, 2020-11-10).
- [Audiobooks](https://www.w3.org/TR/audiobooks/): Recommendation, audiobooks REC-audiobooks-20201110 (Recommendation, 2020-11-10).
