# web-sustainability-guidelines

An agent skill for Web Sustainability Guidelines (WSG).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-sustainability-guidelines
```

Then ask the agent to apply Web Sustainability Guidelines (WSG).

## What it covers

- when reviewing a site or product against the Web Sustainability Guidelines and impact ratings
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                | Status          |
| ----------------------------------- | --------------- |
| Web Sustainability Guidelines (WSG) | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
