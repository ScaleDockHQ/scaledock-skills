# eprivacy

An agent skill for ePrivacy Directive: applying the ePrivacy Directive to electronic communications.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eprivacy
```

Then ask your agent to apply ePrivacy Directive.

## What it covers

- Directive 2002/58/EC of 12 July 2002 concerning the processing of personal data and the protection of privacy in the electronic communications sector, Official Journal L 201, 31 July 2002, pages 37 to 47.
