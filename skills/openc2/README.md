# openc2

An agent skill for OpenC2.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill openc2
```

Then ask the agent to apply OpenC2.

## What it covers

- when sending cybersecurity commands
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                | Status  |
| ------------------- | ------- |
| OpenC2 Language 1.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [OpenC2 Language 1.0](https://docs.oasis-open.org/openc2/oc2ls/v1.0/oc2ls-v1.0.html): OASIS Standard, OpenC2 Language Specification 1.0, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
