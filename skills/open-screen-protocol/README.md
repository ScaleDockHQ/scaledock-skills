# open-screen-protocol

An agent skill for Open Screen Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill open-screen-protocol
```

Then ask the agent to apply Open Screen Protocol.

## What it covers

- when implementing the Open Screen network or application protocol
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                             | Status          |
| -------------------------------- | --------------- |
| Open Screen Network Protocol     | current (track) |
| Open Screen Application Protocol | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Open Screen Network Protocol](https://www.w3.org/TR/openscreen-network/): Working Draft, openscreen-network WD-openscreen-network-20260210 (Working Draft, 2026-02-10).
- [Open Screen Application Protocol](https://www.w3.org/TR/openscreen-application/): Working Draft, openscreen-application WD-openscreen-application-20260210 (Working Draft, 2026-02-10).
