# screen-wake-lock

An agent skill for Screen Wake Lock API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill screen-wake-lock
```

Then ask the agent to apply Screen Wake Lock API.

## What it covers

- when keeping the screen awake
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                 | Status          |
| -------------------- | --------------- |
| Screen Wake Lock API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
