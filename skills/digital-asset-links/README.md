# digital-asset-links

An agent skill for Digital Asset Links.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill digital-asset-links
```

Then ask the agent to apply Digital Asset Links.

## What it covers

- when publishing an assetlinks.json statement
- The version lines in the table below, pinned to the revisions in `metadata.json`.
