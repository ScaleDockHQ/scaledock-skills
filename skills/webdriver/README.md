# webdriver

An agent skill for WebDriver.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webdriver
```

Then ask the agent to apply WebDriver.

## What it covers

- when writing or reviewing a WebDriver classic or BiDi implementation
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line              | Status          |
| ----------------- | --------------- |
| WebDriver Level 1 | current         |
| WebDriver Level 2 | preview (track) |
| WebDriver BiDi    | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [WebDriver](https://www.w3.org/TR/webdriver1/): Recommendation, webdriver1 REC-webdriver1-20180605 (Recommendation, 2018-06-05).
- [WebDriver](https://www.w3.org/TR/webdriver2/): Working Draft, webdriver2 WD-webdriver2-20260702 (Working Draft, 2026-07-02).
- [WebDriver BiDi](https://www.w3.org/TR/webdriver-bidi/): Working Draft, webdriver-bidi WD-webdriver-bidi-20260930 (Working Draft, 2026-09-30).
