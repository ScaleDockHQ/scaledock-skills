# media-ontology

An agent skill for Ontology for Media Resources.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill media-ontology
```

Then ask the agent to apply Ontology for Media Resources.

## What it covers

- when describing media resources
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                 | Status  |
| ------------------------------------ | ------- |
| Ontology for Media Resources 1.0     | current |
| Metadata API for Media Resources 1.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Ontology for Media Resources 1.0](https://www.w3.org/TR/mediaont-10/): Recommendation, mediaont-10 REC-mediaont-10-20120209 (Recommendation, 2012-02-09).
- [Metadata API for Media Resources 1.0](https://www.w3.org/TR/mediaont-api-1.0/): Recommendation, mediaont-api-1.0 REC-mediaont-api-1.0-20140313 (Recommendation, 2014-03-13).
