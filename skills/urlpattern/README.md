# urlpattern

An agent skill for URL Pattern.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill urlpattern
```

Then ask the agent to apply URL Pattern.

## What it covers

- when matching URLs with a pattern
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                        | Status  |
| --------------------------- | ------- |
| URL Pattern Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
