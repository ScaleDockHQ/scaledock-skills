# storage

An agent skill for Storage.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill storage
```

Then ask the agent to apply Storage.

## What it covers

- when using the Storage standard
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status  |
| ----------------------- | ------- |
| Storage Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
