# audio-session

An agent skill for Audio Session.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill audio-session
```

Then ask the agent to apply Audio Session.

## What it covers

- when managing an audio session
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status          |
| ------------- | --------------- |
| Audio Session | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
