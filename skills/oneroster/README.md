# oneroster

An agent skill for OneRoster.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill oneroster
```

Then ask the agent to apply OneRoster.

## What it covers

- when exchanging roster data
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status  |
| ------------- | ------- |
| OneRoster 1.2 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [OneRoster 1.2](https://www.imsglobal.org/spec/oneroster/v1p2/): Specification, OneRoster 1.2 (Specification, 2026-10-06).
