# mls

An agent skill for The Messaging Layer Security (MLS) Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill mls
```

Then ask the agent to apply The Messaging Layer Security (MLS) Protocol.

## What it covers

- when implementing Messaging Layer Security
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| RFC 9420 The Messaging Layer Security (MLS) Protocol | current |
