# device-posture

An agent skill for Device Posture API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill device-posture
```

Then ask the agent to apply Device Posture API.

## What it covers

- when reading a foldable device posture
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line               | Status          |
| ------------------ | --------------- |
| Device Posture API | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.
