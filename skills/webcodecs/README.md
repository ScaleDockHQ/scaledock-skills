# webcodecs

An agent skill for WebCodecs.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webcodecs
```

Then ask the agent to apply WebCodecs.

## What it covers

- when encoding or decoding media in the browser
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line      | Status          |
| --------- | --------------- |
| WebCodecs | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [WebCodecs](https://www.w3.org/TR/webcodecs/): Working Draft, webcodecs WD-webcodecs-20260921 (Working Draft, 2026-09-21).
- [WebCodecs Codec Registry](https://www.w3.org/TR/webcodecs-codec-registry/): Draft Registry, webcodecs-codec-registry (Draft Registry, 2026-09-24).
