# sysml

An agent skill for SysML: writing a SysML model.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill sysml
```

Then ask your agent to apply SysML.

## What it covers

- OMG Systems Modeling Language (SysML) Version 2.0, Part 1 Language Specification, document formal/2026-03-02, March 2026. Version 1.7, document formal/24-01-07, January 2024, is the previous published line.

## Versions

| Line      | Status  |
| --------- | ------- |
| SysML 2.0 | current |
| SysML 1.7 | legacy  |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [SysML 2.0 Language](https://www.omg.org/spec/SysML/2.0/Language/PDF): OMG formal specification, formal/2026-03-02, March 2026.
- [SysML 1.7](https://www.omg.org/spec/SysML/1.7/PDF): OMG formal specification, formal/24-01-07, January 2024.
