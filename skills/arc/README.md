# arc

An agent skill for The Authenticated Received Chain (ARC) Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill arc
```

Then ask the agent to apply The Authenticated Received Chain (ARC) Protocol.

## What it covers

- when sealing or validating an authenticated received chain
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                     | Status  |
| -------------------------------------------------------- | ------- |
| RFC 8617 The Authenticated Received Chain (ARC) Protocol | current |

`references/versions.md` says which line to use and how to upgrade between them.
