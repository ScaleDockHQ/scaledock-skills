# matrix

An agent skill for Matrix.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill matrix
```

Then ask the agent to apply Matrix.

## What it covers

- when implementing a Matrix client or server
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line        | Status  |
| ----------- | ------- |
| Matrix 1.14 | current |

`references/versions.md` says which line to use and how to upgrade between them.
