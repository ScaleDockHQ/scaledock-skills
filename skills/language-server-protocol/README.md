# language-server-protocol

An agent skill for Language Server Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill language-server-protocol
```

Then ask the agent to apply Language Server Protocol.

## What it covers

- when implementing a language server
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status          |
| -------- | --------------- |
| LSP 3.17 | current         |
| LSP 3.18 | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.
