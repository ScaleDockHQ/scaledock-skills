# visa-trusted-agent-protocol

An agent skill for Trusted Agent Protocol.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill visa-trusted-agent-protocol
```

Then ask the agent to apply Trusted Agent Protocol.
