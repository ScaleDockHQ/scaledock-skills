# digital-credentials

An agent skill for Digital Credentials API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill digital-credentials
```

Then ask the agent to apply Digital Credentials API.

## What it covers

- when a site requests or presents digital credentials in the browser
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
