# backstage-catalog

An agent skill for Backstage catalog.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill backstage-catalog
```

Then ask the agent to apply Backstage catalog.

## What it covers

- when describing a Backstage catalog entity
- The version lines in the table below, pinned to the revisions in `metadata.json`.
