# xslt

An agent skill for XSLT.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill xslt
```

Then ask the agent to apply XSLT.

## What it covers

- when transforming XML with XSLT
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                    | Status                |
| ------------------------------------------------------- | --------------------- |
| XSLT 4.0                                                | preview (track)       |
| XSL Transformations (XSLT) Version 3.0                  | current               |
| XSL Transformations (XSLT) Version 2.0 (Second Edition) | supported             |
| XSL Transformations (XSLT) Version 1.0                  | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [XSLT 4.0](https://qt4cg.org/specifications/xslt-40/Overview.html): Community Group draft, xslt-40-preview REC-xmlbase-20090128 (Community Group draft, 2026-10-05).
- [XSL Transformations (XSLT) Version 3.0](https://www.w3.org/TR/xslt-30/): Recommendation, xslt-30 REC-xslt-30-20170608 (Recommendation, 2017-06-08).
- [XSL Transformations (XSLT) Version 2.0 (Second Edition)](https://www.w3.org/TR/xslt20/): Recommendation, xslt20 REC-xslt20-20210330 (Recommendation, 2021-03-30).
- [XSL Transformations (XSLT) Version 1.0](https://www.w3.org/TR/xslt-10/): Recommendation, xslt xslt (Recommendation, 1999-11-16).
