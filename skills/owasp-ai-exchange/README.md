# owasp-ai-exchange

An agent skill for OWASP AI Exchange.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-ai-exchange
```

Then ask the agent to apply OWASP AI Exchange.

## What it covers

- when applying the OWASP AI Exchange
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line              | Status  |
| ----------------- | ------- |
| OWASP AI Exchange | current |

`references/versions.md` says which line to use and how to upgrade between them.
