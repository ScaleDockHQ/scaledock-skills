# writing-assistance-apis

An agent skill for Writing Assistance APIs.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill writing-assistance-apis
```

Then ask the agent to apply Writing Assistance APIs.

## What it covers

- when a page uses the browser writing-assistance APIs
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                  | Status          |
| ------------------------------------- | --------------- |
| Writing Assistance APIs               | current (track) |
| Translator and Language Detector APIs | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
