# oblivious-http

An agent skill for Oblivious HTTP.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill oblivious-http
```

Then ask the agent to apply Oblivious HTTP.

## What it covers

- when sending a request through an oblivious relay
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status  |
| ----------------------- | ------- |
| RFC 9458 Oblivious HTTP | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 9458 Oblivious HTTP](https://www.rfc-editor.org/rfc/rfc9458.html): PROPOSED STANDARD, RFC 9458 (PROPOSED STANDARD, January 20).
