# source-maps

An agent skill for Source maps (ECMA-426).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill source-maps
```

Then ask the agent to apply Source maps (ECMA-426).

## What it covers

- when writing or consuming a source map
- The version lines in the table below, pinned to the revisions in `metadata.json`.
