# websub

An agent skill for WebSub.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill websub
```

Then ask the agent to apply WebSub.

## What it covers

- when publishing or subscribing to webhooks with WebSub
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line   | Status  |
| ------ | ------- |
| WebSub | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
