# device-orientation

An agent skill for Device Orientation and Motion.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill device-orientation
```

Then ask the agent to apply Device Orientation and Motion.

## What it covers

- when reading device orientation or motion events
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                          | Status          |
| ----------------------------- | --------------- |
| Device Orientation and Motion | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.
