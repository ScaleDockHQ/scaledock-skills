# open-agent-spec

An agent skill for Open Agent Specification.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill open-agent-spec
```

Then ask the agent to apply Open Agent Specification.

## What it covers

- when describing agents with Agent Spec
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status  |
