# nist-csf

An agent skill for NIST CSF.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill nist-csf
```

Then ask the agent to apply NIST CSF.

## What it covers

- when applying the Cybersecurity Framework
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line    | Status  |
| ------- | ------- |
| CSF 2.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [CSF 2.0](https://nvlpubs.nist.gov/nistpubs/CSWP/NIST.CSWP.29.pdf): NIST CSWP, CSF 2.0, fetched 2026-10-06 (NIST CSWP, 2026-10-06).
