# cds-hooks

An agent skill for CDS Hooks.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill cds-hooks
```

Then ask the agent to apply CDS Hooks.

## What it covers

- when a clinical system calls decision support
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line          | Status  |
| ------------- | ------- |
| CDS Hooks 2.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [CDS Hooks 2.0](https://cds-hooks.hl7.org/2.0/): Specification, CDS Hooks 2.0 (Specification, 2026-10-06).
