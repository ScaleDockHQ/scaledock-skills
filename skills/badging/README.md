# badging

An agent skill for Badging API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill badging
```

Then ask the agent to apply Badging API.

## What it covers

- when setting an application badge
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line        | Status          |
| ----------- | --------------- |
| Badging API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

The skill was written from these sources, pinned in `metadata.json`:
