# unicode-emoji

An agent skill for Unicode Emoji (UTS #51).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill unicode-emoji
```

Then ask the agent to apply Unicode Emoji (UTS #51).
