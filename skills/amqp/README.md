# amqp

An agent skill for AMQP.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill amqp
```

Then ask the agent to apply AMQP.

## What it covers

- when exchanging messages with AMQP 1.0
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status  |
| -------- | ------- |
| AMQP 1.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [AMQP 1.0](https://docs.oasis-open.org/amqp/core/v1.0/os/amqp-core-overview-v1.0-os.html): OASIS Standard, AMQP 1.0 overview, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
