# xhr

An agent skill for XMLHttpRequest.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill xhr
```

Then ask the agent to apply XMLHttpRequest.

## What it covers

- when maintaining an XMLHttpRequest client
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                           | Status  |
| ------------------------------ | ------- |
| XMLHttpRequest Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
