# png

An agent skill for Portable Network Graphics (PNG).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill png
```

Then ask the agent to apply Portable Network Graphics (PNG).

## What it covers

- when writing or decoding PNG
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                                   | Status                |
| ---------------------------------------------------------------------- | --------------------- |
| Portable Network Graphics (PNG) Specification (Third Edition) Level 3  | current               |
| Portable Network Graphics (PNG) Specification (Second Edition) Level 2 | legacy (upgrade from) |
| Portable Network Graphics (PNG) Specification Level 1                  | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Portable Network Graphics (PNG) Specification (Third Edition)](https://www.w3.org/TR/png-3/): Recommendation, png-3 REC-png-3-20250624 (Recommendation, 2025-06-24).
- [Portable Network Graphics (PNG) Specification (Second Edition)](https://www.w3.org/TR/PNG/): Recommendation, png-2 REC-png-3-20250624 (Recommendation, 2003-11-10).
