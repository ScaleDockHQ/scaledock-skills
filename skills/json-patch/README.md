# json-patch

An agent skill for JavaScript Object Notation (JSON) Patch.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill json-patch
```

Then ask the agent to apply JavaScript Object Notation (JSON) Patch.

## What it covers

- when applying a JSON Patch or a merge patch
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                             | Status  |
| ------------------------------------------------ | ------- |
| RFC 6902 JavaScript Object Notation (JSON) Patch | current |
| RFC 7396 JSON Merge Patch                        | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 6902 JavaScript Object Notation (JSON) Patch](https://www.rfc-editor.org/rfc/rfc6902.html): PROPOSED STANDARD, RFC 6902 (PROPOSED STANDARD, April 2013).
- [RFC 7396 JSON Merge Patch](https://www.rfc-editor.org/rfc/rfc7396.html): PROPOSED STANDARD, RFC 7396 (PROPOSED STANDARD, October 20).
