# web-platform-design-principles

An agent skill for Web Platform Design Principles.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-platform-design-principles
```

Then ask the agent to apply Web Platform Design Principles.

## What it covers

- when designing or reviewing a web platform feature
- The version lines in the table below, pinned to the revisions in `metadata.json`.
