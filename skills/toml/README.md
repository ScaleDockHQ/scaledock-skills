# toml

An agent skill for TOML.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill toml
```

Then ask the agent to apply TOML.

## What it covers

- when parsing TOML
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line       | Status    |
| ---------- | --------- |
| TOML 1.1.0 | current   |
| TOML 1.0.0 | supported |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources
