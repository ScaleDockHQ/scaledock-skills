# owasp-cheat-sheets

An agent skill for OWASP Cheat Sheet Series.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-cheat-sheets
```

Then ask the agent to apply OWASP Cheat Sheet Series.

## What it covers

- when applying an OWASP cheat sheet
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status  |
| ------------------------ | ------- |
| OWASP Cheat Sheet Series | current |

`references/versions.md` says which line to use and how to upgrade between them.
