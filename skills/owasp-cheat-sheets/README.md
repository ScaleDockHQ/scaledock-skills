# owasp-cheat-sheets

An agent skill for OWASP Cheat Sheet Series: applying the core OWASP Cheat Sheets to authentication, sessions, input handling, injection, CSRF and secrets.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill owasp-cheat-sheets
```

Then ask your agent to apply OWASP Cheat Sheet Series.

## What it covers

- The OWASP Cheat Sheet Series: concise application security guidance, one cheat sheet per topic. This skill pins eight core cheat sheets (Authentication, Password Storage, Session Management, Input Validation, Cross Site Scripting Prevention, SQL Injection Prevention, Cross-Site Request Forgery Prevention and Secrets Management), read from the series' Markdown source at a pinned commit.
