# intersection-observer

An agent skill for Intersection Observer.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill intersection-observer
```

Then ask the agent to apply Intersection Observer.

## What it covers

- when observing element visibility
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                  | Status          |
| --------------------- | --------------- |
| Intersection Observer | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
