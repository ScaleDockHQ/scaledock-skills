# r2rml

An agent skill for R2RML.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill r2rml
```

Then ask the agent to apply R2RML.

## What it covers

- when mapping relational data to RDF
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                       | Status  |
| ------------------------------------------ | ------- |
| R2RML: RDB to RDF Mapping Language         | current |
| A Direct Mapping of Relational Data to RDF | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [R2RML: RDB to RDF Mapping Language](https://www.w3.org/TR/r2rml/): Recommendation, r2rml REC-r2rml-20120927 (Recommendation, 2012-09-27).
- [A Direct Mapping of Relational Data to RDF](https://www.w3.org/TR/rdb-direct-mapping/): Recommendation, rdb-direct-mapping REC-rdb-direct-mapping-20120927 (Recommendation, 2012-09-27).
