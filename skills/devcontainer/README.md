# devcontainer

An agent skill for Development Containers.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill devcontainer
```

Then ask the agent to apply Development Containers.

## What it covers

- when writing a devcontainer.json
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                   | Status  |
| ---------------------- | ------- |
| Development Containers | current |

`references/versions.md` says which line to use and how to upgrade between them.
