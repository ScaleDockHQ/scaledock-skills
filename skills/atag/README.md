# atag

An agent skill for Authoring Tool Accessibility Guidelines (ATAG).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill atag
```

Then ask the agent to apply Authoring Tool Accessibility Guidelines (ATAG).

## What it covers

- when building or reviewing an authoring tool for accessibility
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                               | Status                |
| -------------------------------------------------- | --------------------- |
| Authoring Tool Accessibility Guidelines (ATAG) 2.0 | current               |
| Authoring Tool Accessibility Guidelines 1.0        | legacy (upgrade from) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Authoring Tool Accessibility Guidelines (ATAG) 2.0](https://www.w3.org/TR/ATAG20/): Recommendation, ATAG20 NOTE-IMPLEMENTING-ATAG20-20150924 (Recommendation, 2015-09-24).
- [Authoring Tool Accessibility Guidelines 1.0](https://www.w3.org/TR/ATAG10/): Recommendation, ATAG10 REC-ATAG10-20000203 (Recommendation, 2000-02-03).
