# cognitive-accessibility

An agent skill for Making Content Usable for People with Cognitive and Learning Disabilities.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill cognitive-accessibility
```

Then ask the agent to apply Making Content Usable for People with Cognitive and Learning Disabilities.

## What it covers

- when making content usable for people with cognitive and learning disabilities
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                                      | Status          |
| ------------------------------------------------------------------------- | --------------- |
| Making Content Usable for People with Cognitive and Learning Disabilities | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
