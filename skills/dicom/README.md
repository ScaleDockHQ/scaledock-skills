# dicom

An agent skill for DICOM.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill dicom
```

Then ask the agent to apply DICOM.

## What it covers

- when exchanging medical images
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line        | Status  |
| ----------- | ------- |
| DICOM PS3.1 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [DICOM PS3.1](https://dicom.nema.org/medical/dicom/current/output/html/part01.html): Standard, DICOM PS3.1 current HTML (Standard, 2026-10-06).
