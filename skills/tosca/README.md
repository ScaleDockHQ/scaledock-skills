# tosca

An agent skill for TOSCA.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill tosca
```

Then ask the agent to apply TOSCA.

## What it covers

- when describing a cloud application topology
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line      | Status  |
| --------- | ------- |
| TOSCA 2.0 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [TOSCA 2.0](https://docs.oasis-open.org/tosca/TOSCA/v2.0/os/TOSCA-v2.0-os.html): OASIS Standard, TOSCA 2.0, fetched 2026-10-06 (OASIS Standard, 2026-10-06).
