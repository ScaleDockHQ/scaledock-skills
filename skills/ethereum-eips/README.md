# ethereum-eips

An agent skill for Ethereum EIPs.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill ethereum-eips
```

Then ask the agent to apply Ethereum EIPs.

## What it covers

- when implementing ERC-20, EIP-712, ERC-4337, EIP-1193, or ERC-8004
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status  |
| -------- | ------- |
| ERC-20   | current |
| EIP-712  | current |
| ERC-4337 | current |
| EIP-1193 | current |
| ERC-8004 | current |

`references/versions.md` says which line to use and how to upgrade between them.
