# streams

An agent skill for Streams.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill streams
```

Then ask the agent to apply Streams.

## What it covers

- when reading or writing streams
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status  |
| ----------------------- | ------- |
| Streams Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.
