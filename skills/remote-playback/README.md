# remote-playback

An agent skill for Remote Playback API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill remote-playback
```

Then ask the agent to apply Remote Playback API.

## What it covers

- when playing media on a remote device
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                | Status          |
| ------------------- | --------------- |
| Remote Playback API | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:
