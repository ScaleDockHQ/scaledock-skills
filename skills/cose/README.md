# cose

An agent skill for CBOR Object Signing and Encryption (COSE): Structures and Process.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill cose
```

Then ask the agent to apply CBOR Object Signing and Encryption (COSE): Structures and Process.

## What it covers

- when signing or encrypting with COSE
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                                                                                  | Status  |
| --------------------------------------------------------------------------------------------------------------------- | ------- |
| RFC 9052 CBOR Object Signing and Encryption (COSE): Structures and Process                                            | current |
| RFC 9053 CBOR Object Signing and Encryption (COSE): Initial Algorithms                                                | current |
| RFC 9360 CBOR Object Signing and Encryption (COSE): Header Parameters for Carrying and Referencing X.509 Certificates | current |
| RFC 9964 ML-DSA for JSON Object Signing and Encryption (JOSE) and CBOR Object Signing and Encryption (COSE)           | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 9052 CBOR Object Signing and Encryption (COSE): Structures and Process](https://www.rfc-editor.org/rfc/rfc9052.html): INTERNET STANDARD, RFC 9052 (INTERNET STANDARD, August 202).
- [RFC 9053 CBOR Object Signing and Encryption (COSE): Initial Algorithms](https://www.rfc-editor.org/rfc/rfc9053.html): INFORMATIONAL, RFC 9053 (INFORMATIONAL, August 202).
- [RFC 9360 CBOR Object Signing and Encryption (COSE): Header Parameters for Carrying and Referencing X.509 Certificates](https://www.rfc-editor.org/rfc/rfc9360.html): PROPOSED STANDARD, RFC 9360 (PROPOSED STANDARD, February 2).
- [RFC 9964 ML-DSA for JSON Object Signing and Encryption (JOSE) and CBOR Object Signing and Encryption (COSE)](https://www.rfc-editor.org/rfc/rfc9964.html): PROPOSED STANDARD, RFC 9964 (PROPOSED STANDARD, May 2026).
