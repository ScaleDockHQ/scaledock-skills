# dbsc

An agent skill for Device Bound Session Credentials (DBSC).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill dbsc
```

Then ask the agent to apply Device Bound Session Credentials (DBSC).

## What it covers

- when binding a session to a device key
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                     | Status          |
| ---------------------------------------- | --------------- |
| Device Bound Session Credentials Level 1 | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Device Bound Session Credentials](https://www.w3.org/TR/dbsc-1/): First Public Working Draft, dbsc-1 WD-dbsc-1-20250821 (First Public Working Draft, 2025-08-21).
