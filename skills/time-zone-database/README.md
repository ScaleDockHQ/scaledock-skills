# time-zone-database

An agent skill for Procedures for Maintaining the Time Zone Database.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill time-zone-database
```

Then ask the agent to apply Procedures for Maintaining the Time Zone Database.

## What it covers

- when using the IANA time zone database
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                       | Status  |
| ---------------------------------------------------------- | ------- |
| RFC 6557 Procedures for Maintaining the Time Zone Database | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 6557 Procedures for Maintaining the Time Zone Database](https://www.rfc-editor.org/rfc/rfc6557.html): BEST CURRENT PRACTICE, RFC 6557 (BEST CURRENT PRACTICE, February 2).
