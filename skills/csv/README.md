# csv

An agent skill for Common Format and MIME Type for Comma-Separated Values (CSV) Files.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill csv
```

Then ask the agent to apply Common Format and MIME Type for Comma-Separated Values (CSV) Files.

## What it covers

- when reading or writing CSV
- The version lines in the table below, pinned to the revisions in `metadata.json`.
