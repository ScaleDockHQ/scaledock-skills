# html-media-capture

An agent skill for HTML Media Capture.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill html-media-capture
```

Then ask the agent to apply HTML Media Capture.

## What it covers

- when capturing media from a file input
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line               | Status  |
| ------------------ | ------- |
| HTML Media Capture | current |

`references/versions.md` says which line to use and how to upgrade between them.
