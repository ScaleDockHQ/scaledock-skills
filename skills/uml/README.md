# uml

An agent skill for UML: drawing or exchanging a UML model.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill uml
```

Then ask your agent to apply UML.

## What it covers

- OMG Unified Modeling Language (OMG UML) Version 2.5.1, document formal/2017-12-05, December 2017.

## Versions

| Line      | Status  |
| --------- | ------- |
| UML 2.5.1 | current |

`references/versions.md` says which line to use and how to upgrade between them.
