# json

An agent skill for The JavaScript Object Notation (JSON) Data Interchange Format.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill json
```

Then ask the agent to apply The JavaScript Object Notation (JSON) Data Interchange Format.

## What it covers

- when producing or parsing JSON text
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                                                   | Status  |
| ---------------------------------------------------------------------- | ------- |
| RFC 8259 The JavaScript Object Notation (JSON) Data Interchange Format | current |
| RFC 7493 The I-JSON Message Format                                     | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 8259 The JavaScript Object Notation (JSON) Data Interchange Format](https://www.rfc-editor.org/rfc/rfc8259.html): INTERNET STANDARD, RFC 8259 (INTERNET STANDARD, December 2).
- [RFC 7493 The I-JSON Message Format](https://www.rfc-editor.org/rfc/rfc7493.html): PROPOSED STANDARD, RFC 7493 (PROPOSED STANDARD, March 2015).
