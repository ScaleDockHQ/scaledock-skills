# nist-privacy-framework

An agent skill for NIST Privacy Framework.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill nist-privacy-framework
```

Then ask the agent to apply NIST Privacy Framework.

## What it covers

- when applying the Privacy Framework
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                  | Status          |
| --------------------- | --------------- |
| Privacy Framework 1.0 | current         |
| Privacy Framework 1.1 | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Privacy Framework 1.0](https://nvlpubs.nist.gov/nistpubs/CSWP/NIST.CSWP.01162020.pdf): NIST CSWP, Privacy Framework 1.0, fetched 2026-10-06 (NIST CSWP, 2026-10-06).
- [Privacy Framework 1.1](https://www.nist.gov/system/files/documents/2024/06/18/Privacy%20Framework%201.1%20Concept%20Paper%20%286.18.24%29.pdf): Concept paper, Privacy Framework 1.1 concept paper, fetched 2026-10-06 (Concept paper, 2026-10-06).
