# micropub

An agent skill for Micropub.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill micropub
```

Then ask the agent to apply Micropub.

## What it covers

- when creating posts with Micropub
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line     | Status  |
| -------- | ------- |
| Micropub | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Micropub](https://www.w3.org/TR/micropub/): Recommendation, micropub REC-micropub-20170523 (Recommendation, 2017-05-23).
