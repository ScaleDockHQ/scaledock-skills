# webxr

An agent skill for WebXR.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webxr
```

Then ask the agent to apply WebXR.

## What it covers

- when building an immersive or inline XR experience
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
