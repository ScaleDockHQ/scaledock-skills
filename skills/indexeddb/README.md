# indexeddb

An agent skill for Indexed Database API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill indexeddb
```

Then ask the agent to apply Indexed Database API.

## What it covers

- when storing structured data in IndexedDB
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status                |
| ------------------------ | --------------------- |
| Indexed Database API 2.0 | current               |
| Indexed Database API     | legacy (upgrade from) |
| Indexed Database API 3.0 | preview (track)       |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Indexed Database API 2.0](https://www.w3.org/TR/IndexedDB-2/): Recommendation, IndexedDB-2 REC-IndexedDB-2-20180130 (Recommendation, 2018-01-30).
- [Indexed Database API](https://www.w3.org/TR/IndexedDB/): Recommendation, IndexedDB WD-IndexedDB-3-20250813 (Recommendation, 2015-01-08).
- [Indexed Database API 3.0](https://www.w3.org/TR/IndexedDB-3/): Working Draft, IndexedDB-3 WD-IndexedDB-3-20250813 (Working Draft, 2025-08-13).
