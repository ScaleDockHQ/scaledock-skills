# eu-accessibility-act

An agent skill for European Accessibility Act: applying the accessibility requirements for products and services.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill eu-accessibility-act
```

Then ask your agent to apply European Accessibility Act.

## What it covers

- Directive (EU) 2019/882 of 17 April 2019 on the accessibility requirements for products and services, published in Official Journal L 151 of 7 June 2019.

## Versions

| Line                    | Status  |
| ----------------------- | ------- |
| Directive (EU) 2019/882 | current |
