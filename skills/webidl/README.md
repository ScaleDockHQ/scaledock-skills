# webidl

An agent skill for Web IDL.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill webidl
```

Then ask the agent to apply Web IDL.

## What it covers

- when writing or checking Web IDL
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status  |
| ----------------------- | ------- |
| Web IDL Living Standard | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Web IDL Living Standard](https://webidl.spec.whatwg.org/review-drafts/2026-09/): Review Draft, Review Draft 2026-09 (Review Draft, 2026-09).
