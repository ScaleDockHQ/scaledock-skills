# incremental-font-transfer

An agent skill for Incremental Font Transfer.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill incremental-font-transfer
```

Then ask the agent to apply Incremental Font Transfer.

## What it covers

- when transferring fonts incrementally
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                      | Status          |
| ------------------------- | --------------- |
| Incremental Font Transfer | current (build) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Incremental Font Transfer](https://www.w3.org/TR/IFT/): Candidate Recommendation Draft, IFT CRD-IFT-20251118 (Candidate Recommendation Draft, 2025-11-18).
