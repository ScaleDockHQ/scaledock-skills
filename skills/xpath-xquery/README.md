# xpath-xquery

An agent skill for XPath and XQuery.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill xpath-xquery
```

Then ask the agent to apply XPath and XQuery.

## What it covers

- when querying XML with XPath or XQuery
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                                         | Status          |
| -------------------------------------------- | --------------- |
| XML Path Language (XPath) 3.1                | current         |
| XML Path Language (XPath) 3.0                | supported       |
| XQuery 4.0                                   | preview (track) |
| XQuery 3.1: An XML Query Language            | current         |
| XQuery 3.0: An XML Query Language            | supported       |
| XPath and XQuery Functions and Operators 3.1 | current         |
| XQuery and XPath Data Model 3.1              | current         |
| XQueryX 3.1                                  | current         |

`references/versions.md` says which line to use and how to upgrade between them.
