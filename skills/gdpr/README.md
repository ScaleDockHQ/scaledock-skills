# gdpr

An agent skill for GDPR: applying the General Data Protection Regulation.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill gdpr
```

Then ask your agent to apply GDPR.

## What it covers

- Regulation (EU) 2016/679 on the protection of natural persons with regard to the processing of personal data and on the free movement of such data, and repealing Directive 95/46/EC.

## Versions

| Line                     | Status  |
| ------------------------ | ------- |
| Regulation (EU) 2016/679 | current |

`references/versions.md` says which line to use and how to upgrade between them.
