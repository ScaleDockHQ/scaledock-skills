# ogc-api-features

An agent skill for OGC API Features.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill ogc-api-features
```

Then ask the agent to apply OGC API Features.

## What it covers

- when publishing geospatial features
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                    | Status  |
| ----------------------- | ------- |
| OGC API Features Part 1 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [OGC API Features Part 1](https://docs.ogc.org/is/17-069r4/17-069r4.html): Implementation Standard, OGC API - Features - Part 1: Core corrigendum (Implementation Standard, 2026-10-06).
