# github-flavored-markdown

An agent skill for GitHub Flavored Markdown.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill github-flavored-markdown
```

Then ask the agent to apply GitHub Flavored Markdown.

## What it covers

- when parsing GitHub Flavored Markdown
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions
