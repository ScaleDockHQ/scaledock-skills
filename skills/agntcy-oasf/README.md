# agntcy-oasf

An agent skill for Open Agentic Schema Framework.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill agntcy-oasf
```

Then ask the agent to apply Open Agentic Schema Framework.

## What it covers

- when describing agent capabilities with OASF
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line       | Status          |
| ---------- | --------------- |
| OASF 1.1.0 | current         |
| OASF 1.2   | preview (track) |

`references/versions.md` says which line to use and how to upgrade between them.
