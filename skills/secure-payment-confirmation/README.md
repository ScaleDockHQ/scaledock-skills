# secure-payment-confirmation

An agent skill for Secure Payment Confirmation (SPC).

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill secure-payment-confirmation
```

Then ask the agent to apply Secure Payment Confirmation (SPC).

## What it covers

- when confirming a payment with a passkey in the browser
- The version lines in the table below, pinned to the revisions in `metadata.json`.
