# http2

An agent skill for HTTP/2.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill http2
```

Then ask the agent to apply HTTP/2.

## What it covers

- when speaking HTTP/2
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line            | Status  |
| --------------- | ------- |
| RFC 9113 HTTP/2 | current |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [RFC 9113 HTTP/2](https://www.rfc-editor.org/rfc/rfc9113.html): PROPOSED STANDARD, RFC 9113 (PROPOSED STANDARD, June 2022).
