# presentation-exchange

An agent skill for Presentation Exchange.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill presentation-exchange
```

Then ask the agent to apply Presentation Exchange.

## What it covers

- when requesting and submitting verifiable presentations
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                        | Status    |
| --------------------------- | --------- |
| Presentation Exchange 2.1.1 | current   |
| Presentation Exchange 2.1.0 | supported |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Presentation Exchange 2.1.1](https://identity.foundation/presentation-exchange/spec/v2.1.1/): DIF specification, Presentation Exchange v2.1.1, fetched 2026-10-06 (DIF specification, 2026-10-06).
- [Presentation Exchange 2.1.0](https://identity.foundation/presentation-exchange/spec/v2.1.0/): DIF specification, Presentation Exchange v2.1.0, fetched 2026-10-06 (DIF specification, 2026-10-06).
