# web-app-manifest

An agent skill for Web Application Manifest.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill web-app-manifest
```

Then ask the agent to apply Web Application Manifest.

## What it covers

- when writing or parsing a web app manifest
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line                     | Status          |
| ------------------------ | --------------- |
| Web Application Manifest | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.

## Pinned sources

The skill was written from these sources, pinned in `metadata.json`:

- [Web Application Manifest](https://www.w3.org/TR/appmanifest/): Working Draft, appmanifest WD-appmanifest-20260813 (Working Draft, 2026-08-13).
- [Web App Manifest - Application Information](https://www.w3.org/TR/manifest-app-info/): Note, manifest-app-info (Note, 2023-08-21).
