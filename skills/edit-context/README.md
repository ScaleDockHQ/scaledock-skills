# edit-context

An agent skill for EditContext API.

## Install

```bash
npx skills add ScaleDockHQ/scaledock-skills --skill edit-context
```

Then ask the agent to apply EditContext API.

## What it covers

- when implementing a custom text editor
- The version lines in the table below, pinned to the revisions in `metadata.json`.

## Versions

| Line            | Status          |
| --------------- | --------------- |
| EditContext API | current (track) |

`references/versions.md` says which line to use and how to upgrade between them.
