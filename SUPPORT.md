# Support

- **A skill gives wrong or outdated guidance:** open a [bug report](https://github.com/ScaleDockHQ/scaledock-skills/issues/new?template=bug.yml).
- **You want a new skill or a change to one:** open a [skill request](https://github.com/ScaleDockHQ/scaledock-skills/issues/new?template=skill-request.yml).
- **Security issues:** follow [SECURITY.md](SECURITY.md) and never use a public issue.
- **Installing skills:** see the [skills CLI](https://github.com/vercel-labs/skills) docs, or run `npx skills add --help`.
