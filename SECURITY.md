# Security policy

This repo publishes agent skills: markdown instructions, references and small helper scripts that coding agents load and run. A skill that tells an agent to do something unsafe counts as a security issue. Examples are leaking secrets, weakening auth or running untrusted code.

## Reporting a vulnerability

Report it privately through [GitHub security advisories](https://github.com/ScaleDockHQ/scaledock-skills/security/advisories/new). Do not open a public issue.

Include the skill name and version, the file and line, and what an agent would do as a result. We reply within five working days.

## Supported versions

Only the latest version of each skill on `main` gets fixes.
